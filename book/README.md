# AI 책 쓰기 단행본 프로젝트

패스트캠퍼스 강의 **「하루 30분이면 끝! AI로 완성하는 전자책 제작부터 수익화까지」**(송아영)를 기반으로,
2026년 최신 AI 도구 환경을 반영해 새로 집필하는 단행본 원고 저장소입니다.

- **책의 주제**: 전자책 제작부터 수익화까지 (강의와 동일)
- **이 책의 출간 형태**: 종이책 단행본

## 디렉터리 구조

```
book/
├── 기획/     출간기획안, 목차, 도구 최신화 리서치 보고서
├── 원고/     파트·챕터별 본문 원고 (마크다운)
└── 자료/     원본 강의 커리큘럼 등 참고 자료
```

## 원칙

- 강의 커리큘럼은 구조 참고용이며, 본문은 2026년 기준 최신 정보로 새로 집필한다.
- 모든 AI 도구 설명은 집필 시점의 실제 기능·요금을 리서치해 반영한다.
- Claude Code를 활용한 집필·자동화 파트를 포함한다.
