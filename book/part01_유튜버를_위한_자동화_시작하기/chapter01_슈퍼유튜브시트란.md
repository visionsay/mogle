# Chapter 01: '슈퍼유튜브시트'란?

유튜브 채널을 운영하면서 "이 키워드가 정말 먹힐까?", "경쟁 채널은 어떤 전략을 쓰고 있지?", "댓글에서 시청자가 진짜 원하는 게 뭘까?"라는 질문에 시달려본 적이 있는가? 대부분의 유튜버는 이 질문들에 대한 답을 **감(感)**에 의존한다. 하지만 데이터로 답할 수 있다면 어떨까?

**슈퍼유튜브시트**는 구글 스프레드시트와 앱스 스크립트(Apps Script), 그리고 AI를 결합해 만든 유튜브 채널 운영 자동화 시스템이다. 월 수십만 원짜리 유료 도구들이 제공하는 기능을 **평생 무료**로, 그것도 **내 입맛대로 커스터마이징**해서 사용할 수 있다.

이 장에서는 슈퍼유튜브시트가 무엇인지, 왜 필요한지, 그리고 이 시스템이 당신의 유튜브 채널에 어떤 변화를 가져올 수 있는지 알아본다.

---

## 월 99만 원짜리 기능을 평생 무료로

유튜브 채널을 체계적으로 운영하려면 데이터 분석 도구가 필수다. 시장에는 이미 여러 유료 도구가 존재한다. 문제는 **가격**이다.

### 주요 유료 도구 월간 비용 (2026년 6월 기준)

| 도구 | 요금제 | 월 비용(USD) | 월 비용(KRW, 환율 1,380원) |
|------|--------|-------------|--------------------------|
| vidIQ Pro | Pro | $49/월 | 약 67,620원 |
| TubeBuddy | Legend | $49/월 | 약 67,620원 |
| Social Blade | Premium | $9.99/월 | 약 13,786원 |
| Noxinfluencer | VIP | $99/월 | 약 136,620원 |
| **합계** | | **$206.99/월** | **약 285,646원** |

연간으로 환산하면 **약 342만 원**이다. 3년이면 **1,000만 원이 넘는다**. 그리고 이 도구들을 전부 쓰더라도 **내가 원하는 방식으로 데이터를 조합하거나 분석하는 데는 한계**가 있다.

### 슈퍼유튜브시트 vs 유료 도구 기능 비교

|------|-----------|-----------------|--------------|---------|---------------|

| 경쟁 채널 벤치마킹 | ✅ | ✅ | ✅ | ✅ | ✅ (무제한 채널) |

| **월 비용** | **$49** | **$49** | **$9.99** | **$99** | **$0 (무료)** |

핵심은 이것이다. 슈퍼유튜브시트는 유료 도구의 기능을 단순히 **복제**하는 것이 아니라, 유료 도구에서는 **불가능한 기능**까지 제공한다. 댓글 감성 분석, 구독자 이벤트 자동화, AI 기반 인사이트 도출은 어떤 유료 도구에서도 제대로 지원하지 않는 영역이다.

물론 YouTube Data API에는 일일 쿼터(quota) 제한이 있다. 기본 10,000 유닛/일이다. 하지만 실제로 채널 1~2개를 운영하면서 분석하는 수준에서는 이 쿼터를 다 쓰기 어렵다. 그리고 쿼터를 효율적으로 관리하는 방법도 이 책에서 다룬다.

## 도파민 터지는 조회수 폭발

데이터 분석이 실제로 조회수 폭발로 이어지는 과정을 구체적인 지표 패턴으로 살펴보자.

### 패턴 1: 키워드 갭(Keyword Gap) 발견

슈퍼유튜브시트로 특정 키워드의 검색량과 경쟁 영상 수를 분석했을 때, 다음과 같은 **골든 키워드**를 발견할 수 있다.

```
키워드: "아이폰 16 배터리 절약 설정"
─────────────────────────────────
검색 관심도(Google Trends): 78/100
경쟁 영상 수(최근 7일 업로드): 3개
상위 10개 영상 평균 조회수: 45,000회
상위 10개 영상 평균 구독자: 12,000명
─────────────────────────────────
판정: ★★★★★ 골든 키워드
이유: 높은 검색 관심도 대비 경쟁 영상 극소수
예상 조회수(구독자 5,000명 기준): 15,000~30,000회
```

이런 키워드를 **수작업**으로 찾으려면 유튜브 검색창에 키워드를 하나하나 입력하고, 경쟁 영상을 일일이 확인해야 한다. 슈퍼유튜브시트는 이 과정을 **한 번의 실행으로 수백 개 키워드에 대해 자동 수행**한다.

### 패턴 2: 업로드 타이밍 최적화

```
채널 분석 결과 (최근 90일 데이터)
─────────────────────────────────
요일별 평균 첫 24시간 조회수:
  월요일: 2,340회
  화요일: 3,120회 ★
  수요일: 2,890회
  목요일: 3,450회 ★★
  금요일: 2,100회
  토요일: 1,890회
  일요일: 2,560회

시간대별 평균 첫 1시간 조회수:
  오전 6-9시:   180회
  오전 9-12시:  320회
  오후 12-15시: 410회 ★
  오후 15-18시: 580회 ★★★
  오후 18-21시: 490회 ★★
  오후 21-24시: 350회
─────────────────────────────────
최적 업로드 시점: 목요일 오후 15-16시
```

이 데이터를 기반으로 업로드 시점만 바꿔도 **첫 24시간 조회수가 40~60% 증가**하는 사례가 실제로 나타난다. 유튜브 알고리즘은 초기 반응(CTR, 시청 지속 시간)을 중시하기 때문이다.

### 패턴 3: 썸네일/제목 A/B 테스트 데이터

```
영상 제목 변경 전후 비교 (72시간 추적)
─────────────────────────────────
변경 전: "코딩 배우는 방법 총정리"
  노출 대비 클릭률(CTR): 3.2%
  평균 시청 시간: 4분 12초

변경 후: "비전공자가 3개월 만에 취업한 코딩 공부법"
  노출 대비 클릭률(CTR): 7.8% (↑143%)
  평균 시청 시간: 6분 34초 (↑56%)
─────────────────────────────────
```

슈퍼유튜브시트는 이런 지표 변화를 **자동으로 추적하고 기록**한다. 매번 유튜브 스튜디오에 들어가서 수치를 확인할 필요가 없다.

## 유튜버의 숙명, 지루한 트렌드 조사

유튜브 채널을 운영하는 사람이라면 누구나 겪는 고통이 있다. **트렌드 조사**다.

### 수작업 트렌드 조사의 현실

일반적인 유튜버의 트렌드 조사 프로세스를 시간으로 환산해보자.

```
1. 유튜브 인기 급상승 탐색:        30분
2. 경쟁 채널 최신 영상 확인 (5개):  45분
3. 키워드 검색 및 트렌드 파악:      60분
4. 댓글 분석 (시청자 반응 확인):    40분
5. 관련 뉴스/SNS 트렌드 확인:      30분
6. 콘텐츠 기획안 작성:             45분
─────────────────────────────────
총 소요 시간: 약 4시간 10분
주 3회 업로드 기준 월간: 약 50시간
```

**월 50시간**. 풀타임 직장인의 주간 근무 시간보다 많다. 그런데 이 조사를 해도 결과가 **정확하다는 보장이 없다**. 인간의 눈으로 훑어보는 것이기 때문에 놓치는 트렌드가 반드시 존재한다.

### 기회비용의 문제

트렌드를 1시간 늦게 포착하면 어떤 일이 벌어지는가?

- **빠른 포착**: 트렌드 초기에 영상 업로드 → 유튜브 알고리즘이 "관련 영상"으로 밀어줌 → 조회수 폭발
- **늦은 포착**: 이미 대형 채널이 선점 → 알고리즘에서 밀림 → 같은 주제여도 조회수 1/10

유튜브에서 **속도는 곧 조회수**다. 슈퍼유튜브시트는 이 조사 과정을 **자동화**해서 4시간을 **10분으로 줄인다**. 그리고 사람이 놓치는 패턴까지 AI가 잡아낸다.

### 감(感) vs 데이터

많은 유튜버가 "나는 감으로 해도 잘 돼"라고 말한다. 하지만 데이터를 보면 이야기가 달라진다.

| 의사결정 방식 | 평균 영상 성공률* | 월 평균 조회수 성장률 |
|--------------|-------------------|---------------------|
| 순수 감 의존 | 15~20% | 3~5% |
| 부분적 데이터 활용 | 30~40% | 8~12% |
| 체계적 데이터 분석 | 50~65% | 15~25% |

*성공률: 채널 평균 조회수 대비 150% 이상 달성한 영상의 비율

감이 좋은 크리에이터도 있다. 하지만 **감 + 데이터**를 결합하면 그 감이 더 정확해진다. 슈퍼유튜브시트는 감을 **데이터로 검증하는 도구**다.

## 슈퍼유튜브시트의 시작

슈퍼유튜브시트는 하나의 단순한 불만에서 시작되었다.

> "왜 유튜브 데이터를 분석하려면 매달 돈을 내야 하지?"

YouTube Data API는 **무료**다. 구글 스프레드시트도 **무료**다. 앱스 스크립트도 **무료**다. 그런데 이 무료 도구들을 조합해서 데이터를 분석하는 서비스는 전부 **유료**다. 여기에 의문을 품은 것이 시작이었다.

처음에는 간단했다. 구글 스프레드시트에서 앱스 스크립트로 YouTube Data API를 호출해 영상 정보를 가져오는 것. 코드 30줄이면 충분했다.

```javascript
function getVideoInfo(videoId) {
  const url = `https://www.googleapis.com/youtube/v3/videos?part=snippet,statistics&id=${videoId}&key=${API_KEY}`;
  const response = UrlFetchApp.fetch(url);
  const data = JSON.parse(response.getContentText());
  
  if (data.items && data.items.length > 0) {
    const video = data.items[0];
    return {
      title: video.snippet.title,
      views: video.statistics.viewCount,
      likes: video.statistics.likeCount,
      comments: video.statistics.commentCount
    };
  }
  return null;
}
```

하지만 여기서 멈출 수 없었다. "영상 하나가 아니라 키워드로 검색한 모든 영상을 한 번에 분석할 수는 없을까?", "경쟁 채널의 영상을 자동으로 모니터링할 수는 없을까?", "댓글을 AI로 분석해서 시청자가 진짜 원하는 콘텐츠를 찾을 수는 없을까?"

질문이 쌓이면서 시스템이 점점 진화했다. 그리고 2026년 현재, 슈퍼유튜브시트는 6가지 핵심 기능을 갖춘 **완전한 유튜브 채널 운영 자동화 시스템**이 되었다.

## 슈퍼유튜브시트의 미친 기능 6가지

### 기능 1: 키워드 기반 영상 검색 + 메트릭스 수집

키워드를 입력하면 YouTube Data API를 통해 관련 영상을 검색하고, 각 영상의 핵심 지표를 자동으로 수집한다.

**수집 데이터:**
- 영상 제목, 채널명, 업로드 일자
- 조회수, 좋아요 수, 댓글 수
- 영상 길이, 태그, 카테고리
- 썸네일 URL, 영상 설명

**활용 시나리오:**
```
[스프레드시트 입력]
A1: 검색 키워드 → "파이썬 독학"
A2: 검색 기간   → "최근 30일"
A3: 최대 결과수 → 50

[자동 수집 결과]
B열: 영상 제목
C열: 채널명
D열: 조회수
E열: 좋아요 수
F열: 댓글 수
G열: 업로드일
H열: 영상 길이
I열: 조회수/구독자 비율
J열: 참여율(좋아요+댓글/조회수)
```

단순히 데이터를 나열하는 것이 아니다. **조회수/구독자 비율**(뷰 레이트)과 **참여율**을 자동 계산해서 어떤 영상이 알고리즘에 의해 밀리고 있는지까지 파악할 수 있다.

### 기능 2: 채널 벤치마킹

경쟁 채널이나 롤모델 채널의 성과를 자동으로 추적하고 내 채널과 비교한다.

**벤치마킹 항목:**
- 구독자 수 변화 추이
- 최근 영상 평균 조회수
- 업로드 빈도 및 패턴
- 주력 키워드 및 카테고리
- 영상 길이 분포
- 썸네일 스타일 분석 (AI 활용)

```
[채널 벤치마킹 보고서 - 자동 생성]
─────────────────────────────────────────
비교 채널: 코딩하는 거니 vs 내 채널

              코딩하는 거니    내 채널      차이
구독자:       125,000        8,500       14.7배
평균 조회수:   32,000         2,100       15.2배
업로드 빈도:   주 2회          주 1회       2배
평균 영상길이:  12분 30초      18분 45초    내가 50% 길음
평균 참여율:   4.2%           6.8%        내가 62% 높음 ★
─────────────────────────────────────────
AI 인사이트: 참여율이 높다는 것은 시청자 충성도가
강하다는 의미입니다. 업로드 빈도를 주 2회로 늘리고
영상 길이를 12~14분으로 최적화하면 알고리즘 노출
증가가 예상됩니다.
```

### 기능 3: 댓글 수집 및 AI 감성 분석

특정 영상이나 채널의 댓글을 자동으로 수집하고, Gemini AI를 활용해 감성 분석을 수행한다.

**분석 결과 예시:**

```
[댓글 감성 분석 결과]
─────────────────────────────────────────
총 댓글 수: 847개
긍정: 623개 (73.6%)
중립: 156개 (18.4%)
부정: 68개 (8.0%)

주요 긍정 키워드: "설명 잘해주셔서", "이해됐어요", "최고"
주요 부정 키워드: "음질", "너무 빨라요", "자막"
주요 요청사항:
  1. "심화 강의도 만들어주세요" (34회 언급)
  2. "실습 파일 공유해주세요" (21회 언급)
  3. "라이브로도 해주세요" (15회 언급)
─────────────────────────────────────────
→ 다음 콘텐츠 추천: "심화 편" 시리즈 기획
```

댓글에서 **다음 콘텐츠 아이디어**를 자동으로 추출하는 것이다. 시청자가 직접 말해주는 수요를 AI가 정리해준다.

### 기능 4: 트렌드 탐지

특정 카테고리나 키워드 그룹에서 **급상승하는 트렌드**를 자동으로 탐지한다.

**작동 방식:**
1. 지정한 키워드 그룹의 최근 영상을 주기적으로 스캔
2. 평소 대비 조회수 급증 패턴을 감지
3. 새로운 키워드의 출현을 추적
4. 트렌드 알림을 이메일 또는 스프레드시트로 전송

```
[트렌드 알림 - 2026.06.27 09:00]
─────────────────────────────────────────
🔥 급상승 감지: "비전 프로 2"

관련 지표:
- 최근 24시간 관련 영상 업로드 수: 47개 (평소 대비 820% ↑)
- 관련 키워드 검색 관심도: 89/100 (전일 12/100)
- 상위 영상 평균 조회수: 125,000회 (1시간 내)

경쟁 분석:
- 대형 채널(구독자 10만+) 업로드 수: 8개
- 중형 채널(구독자 1~10만) 업로드 수: 15개
- 소형 채널(구독자 1만 미만) 업로드 수: 24개

추천: 즉시 업로드 가능한 콘텐츠가 있다면 6시간 내
업로드를 권장합니다. 소형 채널 비율이 높아 아직
경쟁 진입 가능합니다.
─────────────────────────────────────────
```

### 기능 5: 구독자 이벤트 자동화

구독자 수가 특정 목표에 도달하면 자동으로 이벤트를 실행한다.

**자동화 시나리오:**
- 구독자 1,000명 달성 시 → 감사 커뮤니티 게시물 자동 작성 준비
- 구독자 10,000명 달성 시 → 이벤트 안내 이메일 자동 발송
- 일일 구독자 증감 → 스프레드시트 자동 기록 + 이상 감지

```javascript
// 구독자 마일스톤 체크 (매시간 자동 실행)
function checkSubscriberMilestone() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName('구독자추적');
  const channelId = sheet.getRange('B1').getValue();
  
  const currentSubs = getSubscriberCount(channelId);
  const lastSubs = sheet.getRange('B2').getValue();
  
  // 마일스톤 목록
  const milestones = [1000, 5000, 10000, 50000, 100000];
  
  for (const milestone of milestones) {
    if (lastSubs < milestone && currentSubs >= milestone) {
      triggerMilestoneEvent(milestone, currentSubs);
    }
  }
  
  // 기록 업데이트
  sheet.getRange('B2').setValue(currentSubs);
  sheet.getRange('B3').setValue(new Date());
  
  // 일일 변화량 기록
  logDailyChange(currentSubs - lastSubs);
}
```

### 기능 6: AI 기반 종합 분석

수집된 모든 데이터를 Gemini AI에 전달해 **종합적인 채널 운영 인사이트**를 도출한다.

**AI 분석 영역:**
- 콘텐츠 전략 제안 (어떤 주제, 어떤 형식)
- 제목/썸네일 최적화 제안
- 업로드 스케줄 최적화
- 시청자 페르소나 분석
- 채널 성장 예측

```
[AI 종합 분석 리포트]
─────────────────────────────────────────
채널: 코딩으로 먹고살기
분석 기간: 2026.05.27 ~ 2026.06.27

1. 콘텐츠 성과 요약
   - 이번 달 최고 성과 영상: "2026 개발자 연봉 현실" (85,000회)
   - 성공 요인: 시의성 높은 키워드 + 데이터 기반 콘텐츠
   - 부진 영상: "Git 브랜치 전략" (1,200회)
   - 부진 요인: 경쟁 포화 키워드 + 타이밍 미스

2. 다음 달 콘텐츠 추천
   ① "AI 코딩 에이전트 실무 활용법" (예상 조회수: 40,000~60,000)
   ② "비전공 개발자 포트폴리오 만들기" (예상 조회수: 25,000~35,000)
   ③ "2026 하반기 IT 취업 전망" (예상 조회수: 50,000~80,000)

3. 채널 건강도 점수: 78/100
   - 업로드 일관성: 85점
   - 시청자 참여도: 92점
   - 키워드 최적화: 65점 (개선 필요)
   - 썸네일 CTR: 72점

```

이 6가지 기능은 각각 독립적으로도 강력하지만, **하나의 스프레드시트 안에서 유기적으로 연결**될 때 진정한 위력을 발휘한다. 키워드 검색 결과가 트렌드 탐지에 반영되고, 댓글 분석 결과가 AI 종합 분석의 입력값이 되는 식이다.

## 유튜브가 가져온 놀라운 변화

유튜브는 단순한 영상 플랫폼이 아니다. 2026년 현재, 유튜브는 **직업**이고, **사업**이고, **자산**이다.

### 수익 구조의 다변화

유튜브 크리에이터의 수익은 광고 수익만이 아니다. 데이터를 체계적으로 분석하는 채널은 다양한 수익원을 구축한다.

```
[유튜브 크리에이터 수익 구조 예시]
─────────────────────────────────────────
채널 규모: 구독자 30,000명

1. 애드센스 광고 수익:     월 150~300만 원
2. 브랜드 협찬:           월 200~500만 원 (영상 2~3건)
3. 온라인 강의 판매:       월 100~200만 원
4. 멤버십/슈퍼챗:         월 30~50만 원
5. 제휴 마케팅:           월 50~100만 원
─────────────────────────────────────────
월 총수익 범위: 530~1,150만 원
```

여기서 주목할 점은 **구독자 3만 명**이면 이 정도 수익이 가능하다는 것이다. 구독자 100만 명이 필요하지 않다. **데이터 기반으로 정확한 타겟에게 정확한 콘텐츠를 제공**하면 적은 구독자로도 충분한 수익을 만들 수 있다.

### 커리어 전환의 도구

유튜브 채널 운영 경험은 다음과 같은 커리어 기회로 이어진다.

- **데이터 분석 역량**: 유튜브 데이터를 다루는 과정에서 자연스럽게 데이터 분석 능력이 향상된다
- **마케팅 전문성**: SEO, 콘텐츠 마케팅, 소셜미디어 마케팅의 실전 경험
- **기술적 역량**: 앱스 스크립트, API 연동, 자동화 시스템 구축 능력
- **개인 브랜딩**: 특정 분야의 전문가로서의 인지도 확보

슈퍼유튜브시트를 구축하는 과정 자체가 **기술적 성장**이다. 구글 앱스 스크립트를 배우고, API를 다루고, AI를 활용하는 경험은 유튜브를 넘어 **어디서든 통하는 역량**이 된다.

## 그래서 이 책이 필요한 사람이 누군데요?

### 이 책이 딱 맞는 사람

**1. 유튜브를 시작했지만 성장이 멈춘 크리에이터**

구독자 100~10,000명 구간에서 정체된 채널 운영자. 감으로 콘텐츠를 만들다가 한계를 느낀 사람. 데이터 기반 의사결정으로 돌파구를 찾고 싶은 사람.

**2. 유튜브를 시작하려는 예비 크리에이터**

시작부터 데이터 기반으로 전략적으로 접근하고 싶은 사람. 시행착오를 줄이고 효율적으로 채널을 성장시키고 싶은 사람.

**3. 유료 도구 비용이 부담되는 크리에이터**

vidIQ, TubeBuddy 등의 유료 요금제를 사용하고 있지만 비용 대비 효과에 의문을 느끼는 사람. 동일하거나 더 나은 기능을 무료로 구축하고 싶은 사람.

**4. 자동화와 AI에 관심 있는 크리에이터**

반복적인 작업을 자동화하고 싶은 사람. AI를 실무에 활용하는 방법을 배우고 싶은 사람. 코딩 경험이 없어도 괜찮다. 이 책은 **바이브 코딩**(AI에게 코드를 작성시키는 방법)부터 시작한다.

**5. MCN이나 에이전시에서 채널을 관리하는 실무자**

여러 채널의 데이터를 효율적으로 모니터링하고 싶은 사람. 리포트 자동화가 필요한 사람.

### 이 책이 맞지 않는 사람

- 이미 구독자 100만 명 이상이고 전담 데이터 분석팀이 있는 대형 크리에이터
- 유튜브가 아닌 다른 플랫폼(인스타, 틱톡)만 운영하는 사람
- 데이터 분석 자체에 전혀 관심이 없고 순수 창작에만 집중하고 싶은 사람

### 이 책을 읽고 나면

- **슈퍼유튜브시트**를 직접 구축해서 나만의 유튜브 분석 시스템을 갖게 된다
- **바이브 코딩**으로 코딩 경험 없이도 구글 앱스 스크립트를 작성할 수 있게 된다
- **YouTube Data API**를 자유자재로 활용할 수 있게 된다
- **Gemini AI**를 연동해 데이터에서 인사이트를 자동 추출할 수 있게 된다
- **자동화 시스템**을 구축해 반복 작업에서 해방된다

다음 장에서는 이 모든 것의 시작점인 **바이브 코딩**과 **제미나이(Gemini)**에 대해 알아본다. 코딩을 한 번도 해본 적 없는 사람도 AI의 도움을 받아 강력한 자동화 시스템을 만들 수 있다. 그 방법을 지금부터 배워보자.
