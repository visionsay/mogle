# Chapter 13: 유튜버를 위한 구글 노트북LM 200% 활용법

앞 장에서 노트북LM의 기본을 익혔다. 이제 실전이다. 이 장에서는 유튜브 채널 운영의 모든 국면에서 노트북LM을 활용하는 **구체적인 프롬프트와 워크플로우**를 다룬다. "무엇을 물어봐야 하는지 모르겠다"는 말이 나오지 않도록, 상황별로 바로 복사해서 사용할 수 있는 질문 템플릿을 총정리한다.

---

## [바로 실습] 내 채널 분석하기

가장 먼저 해야 할 일은 **내 채널을 객관적으로 들여다보는 것**이다. 유튜브 스튜디오에서도 기본적인 통계를 볼 수 있지만, 노트북LM은 **영상 콘텐츠 자체를 분석**한다는 점에서 차원이 다르다. 조회수나 클릭률 같은 숫자가 아니라, "내가 어떤 이야기를 어떤 방식으로 하고 있는가"를 파악하는 것이다.

### 소스 준비

```
[내 채널 분석용 노트북 세팅]
─────────────────────────────────
노트북 이름: "내 채널 콘텐츠 분석 — 2026년 6월"

추가할 소스:
1. 내 채널 조회수 Top 10 영상 (YouTube URL × 10)
   → 유튜브 스튜디오 → 콘텐츠 → 조회수 순 정렬
   
2. 내 채널 최근 업로드 10개 영상 (YouTube URL × 10)
   → 최근 트렌드와 현재 전략 파악용

3. 내 채널 조회수 하위 5개 영상 (YouTube URL × 5)
   → 실패 패턴 분석용 (성공만 보면 반쪽 분석)
   
4. 채널 성과 데이터 (복사한 텍스트 × 1)
   → 슈퍼유튜브시트에서 제목, 조회수, 좋아요, 
     댓글수, 업로드일을 복사하여 추가

총 소스: 26개
─────────────────────────────────
```

### 분석 프롬프트 — 콘텐츠 패턴 분석

소스를 추가했으면 다음 프롬프트를 순서대로 입력한다. 각 프롬프트는 독립적으로도 사용 가능하지만, 순서대로 진행하면 점점 깊은 분석이 가능하다.

**프롬프트 1: 주제와 키워드 분석**

```
내 영상들의 공통 주제와 키워드를 분석해주세요.

다음 형식으로 정리해주세요:
1. 가장 자주 다루는 주제 Top 5 (각 주제별 해당 영상 목록 포함)
2. 자주 등장하는 키워드 Top 10
3. 주제 간의 연관성 맵 (어떤 주제가 어떤 주제와 자주 함께 다뤄지는지)
4. 아직 다루지 않았지만 다뤄볼 만한 관련 주제 제안
```

**프롬프트 2: 성공 영상 vs 실패 영상 비교**

```
조회수가 높은 영상과 낮은 영상의 차이를 다각도로 분석해주세요.

분석 항목:
1. 제목 패턴의 차이 (길이, 구조, 사용된 단어)
2. 도입부 방식의 차이 (처음 1분에 어떤 이야기를 하는지)
3. 콘텐츠 구조의 차이 (정보 전달 방식, 스토리텔링 유무)
4. 주제 선택의 차이 (어떤 주제가 반응이 좋고, 어떤 주제가 안 좋은지)
5. 결론: 내 채널에서 "잘되는 콘텐츠"의 공식은 무엇인지 정리
```

**프롬프트 3: SWOT 분석**

```
내 콘텐츠의 강점과 약점을 SWOT 분석해주세요.

S(강점): 내 콘텐츠가 잘하고 있는 것
W(약점): 개선이 필요한 부분
O(기회): 아직 활용하지 않고 있는 기회 영역
T(위협): 주의해야 할 리스크

각 항목에 대해 근거가 되는 영상을 구체적으로 인용해주세요.
마지막에 "지금 당장 개선할 수 있는 액션 아이템 3가지"를 제안해주세요.
```

**프롬프트 4: 도입부 패턴 분석**

```
영상 도입부(처음 30초~1분)의 패턴을 분석하고, 
가장 효과적인 후킹 방식을 알려주세요.

분석해야 할 것:
1. 각 영상의 첫 문장/첫 30초 내용 정리
2. 도입부 유형 분류 (질문형, 결론선제시형, 스토리형, 충격형 등)
3. 어떤 도입부 유형이 시청자 반응(조회수/댓글)이 가장 좋았는지
4. 개선이 필요한 도입부 사례와 구체적인 대안 제시
```

### 분석 결과 활용법

노트북LM이 분석 결과를 제시하면, **노트 패널에 핵심 인사이트를 저장**하라. 그리고 그 인사이트를 다음과 같이 활용한다.

```
[분석 결과 → 실행 계획 변환]
─────────────────────────────────

분석 결과 예시:
"조회수 상위 영상의 제목은 모두 '숫자 + 결과'를 포함하고 있음"

→ 실행 계획:
  · 다음 5개 영상 제목에 구체적 숫자 포함
  · "3가지 방법", "7일 만에", "5분 완성" 패턴 활용
  · A/B 테스트: 숫자 있는 제목 vs 없는 제목 비교

분석 결과 예시:
"도입부에서 '오늘은 ~에 대해 알아보겠습니다'로 시작하는 
 영상의 조회수가 상대적으로 낮음"

→ 실행 계획:
  · 도입부 템플릿을 '결론 먼저' 방식으로 변경
  · "이걸 모르면 ~한다" 형태의 후킹 테스트
  · 첫 5초 이내에 핵심 메시지 전달
─────────────────────────────────
```

## [바로 실습] 내 팬덤 이해하기

유튜브 채널의 진정한 자산은 구독자가 아니라 **팬덤**이다. 팬덤을 이해한다는 것은 "내 시청자가 정말로 원하는 것이 무엇인지"를 아는 것이다. 댓글 데이터는 이를 파악하는 가장 직접적인 수단이다.

### 소스 준비

```
[팬덤 분석용 소스 세팅]
─────────────────────────────────

1. 댓글 데이터 수집 (슈퍼유튜브시트 활용)
   → "댓글 수집" 기능으로 최근 영상 20개의 댓글 추출
   → 댓글 내용, 작성자, 좋아요 수, 작성일 포함

2. 노트북LM에 소스 추가
   → "복사한 텍스트" 옵션으로 댓글 데이터 추가
   → 영상별로 나누어 추가하면 더 정밀한 분석 가능

예시 소스 구성:
├── "인기 영상 댓글 모음 (Top 10 영상, 총 2,000개 댓글)"
├── "최근 영상 댓글 모음 (최근 10개 영상, 총 800개 댓글)"
└── "부정적 댓글 모음 (별도 필터링)"
─────────────────────────────────
```

### 분석 프롬프트 — 시청자 니즈 파악

**프롬프트 1: 콘텐츠 요청 분석**

```
댓글에서 시청자들이 가장 많이 요청하는 콘텐츠는 무엇인가요?

다음 기준으로 분석해주세요:
1. "~해주세요", "~다뤄주세요", "~궁금합니다" 등 요청성 댓글 전체 수집
2. 요청 주제를 카테고리별로 분류
3. 각 카테고리별 요청 빈도 순위
4. 가장 많이 요청된 주제 Top 5와 해당 댓글 원문 인용
5. 이 요청들을 반영한 영상 기획안 초안 제안
```

**프롬프트 2: 감성 분석**

```
긍정적 댓글과 부정적 댓글의 비율과 주요 키워드를 분석해주세요.

분석 항목:
1. 전체 댓글의 감성 비율 (긍정 / 중립 / 부정)
2. 긍정 댓글에서 가장 많이 언급되는 키워드 Top 5
3. 부정 댓글에서 가장 많이 언급되는 키워드 Top 5
4. 건설적 비판(개선 제안)과 단순 비난의 비율
5. 감성별 대표 댓글 5개씩 인용
6. 부정적 피드백 중 실제로 반영할 가치가 있는 의견 정리
```

**프롬프트 3: 핵심 팬 분석**

```
가장 활발하게 활동하는 팬(자주 댓글 다는 사람)의 관심사를 
파악해주세요.

분석 요청:
1. 여러 영상에 걸쳐 반복적으로 댓글을 단 사용자 식별
2. 이 핵심 팬들이 주로 어떤 주제에 반응하는지
3. 핵심 팬들이 공통적으로 사용하는 표현이나 관심사
4. 핵심 팬들의 댓글 톤과 특징
5. 핵심 팬층을 더 두텁게 만들기 위한 전략 제안
```

**프롬프트 4: 시청자 페르소나 생성**

```
댓글 데이터를 기반으로 시청자 페르소나 3가지를 만들어주세요.

각 페르소나에 포함할 항목:
- 이름 (가상)
- 추정 연령대
- 관심 주제
- 채널을 찾게 된 계기 (추정)
- 가장 좋아하는 콘텐츠 유형
- 불만이나 아쉬운 점
- 이 페르소나를 만족시키기 위한 콘텐츠 전략

근거가 되는 실제 댓글을 각 페르소나별로 3개 이상 인용해주세요.
```

### 팬덤 분석 결과 활용 시나리오

```
[팬덤 분석 → 콘텐츠 전략 반영 예시]
─────────────────────────────────

발견: "댓글의 23%가 '더 자세한 설명'을 요청"
→ 전략: 기존 인기 영상의 심화편(Deep Dive) 시리즈 기획

발견: "핵심 팬 30명이 모두 '초보자용 콘텐츠'에 반응"
→ 전략: 초보자 대상 입문 시리즈를 정기 콘텐츠로 편성

발견: "부정 댓글의 40%가 '음질/화질' 관련"
→ 전략: 장비 업그레이드 또는 편집 개선에 투자

발견: "시청자 페르소나 1(직장인)이 '출퇴근길에 듣는다'고 언급"
→ 전략: 시각 자료 의존도를 낮추고 음성으로도 
        이해 가능한 콘텐츠 구성 병행
─────────────────────────────────
```

## [바로 실습] 인기 채널의 성공 비결 훔쳐오는 법

경쟁 분석은 유튜브 성장의 가장 효율적인 지름길이다. 성공한 채널은 이미 시행착오를 거쳐 최적의 전략을 찾아놓았다. 그 전략을 **역설계(Reverse Engineering)**하는 것이 핵심이다.

### 소스 준비

```
[경쟁 채널 분석용 노트북 세팅]
─────────────────────────────────
노트북 이름: "경쟁 채널 역설계 — [채널명]"

추가할 소스:
1. 경쟁 채널 조회수 Top 10 영상 (YouTube URL × 10)
   → 이 채널의 "검증된 히트작"

2. 경쟁 채널 최근 업로드 10개 (YouTube URL × 10)
   → 이 채널의 "현재 전략"

3. 경쟁 채널의 구독자 수, 총 조회수 등 기본 정보
   (복사한 텍스트 × 1)
   → 슈퍼유튜브시트의 채널 벤치마킹 데이터

총 소스: 21개
─────────────────────────────────
```

### 분석 프롬프트 — 전략 역설계

**프롬프트 1: 콘텐츠 전략 역설계**

```
이 채널의 콘텐츠 전략을 역설계해주세요.

다음 관점에서 분석해주세요:
1. 영상 구조: 도입-전개-결론의 공통 패턴
2. 제목 패턴: 반복적으로 사용되는 제목 구조와 키워드
3. 주제 선정 방식: 어떤 기준으로 주제를 선택하는지
4. 업로드 빈도와 패턴: 주기성이 있는지
5. CTA(Call to Action) 패턴: 구독/좋아요 유도 방식
6. 이 전략이 성공하는 이유에 대한 분석
```

**프롬프트 2: 시리즈/포맷 분석**

```
이 채널에서 가장 성공적인 시리즈나 포맷은 무엇이고, 
왜 성공했나요?

분석해야 할 것:
1. 반복되는 시리즈나 포맷 식별 (유사한 구조의 영상 그룹핑)
2. 각 시리즈/포맷별 특징과 공통점
3. 가장 성공한 시리즈의 성공 요인
4. 시리즈 간의 연결 방식 (시청자를 다른 영상으로 유도하는 방법)
5. 내 채널에 도입할 수 있는 시리즈 포맷 3가지 제안
```

**프롬프트 3: 스크립트 구조 분석**

```
이 채널의 스크립트 구조를 분석해주세요.

다음을 중심으로 분석:
1. 도입부 패턴 (첫 30초에 무엇을 하는지)
2. 전환 방식 (토픽 간 전환을 어떻게 하는지)
3. 정보 전달 방식 (나열형 vs 스토리텔링형 vs 대화형)
4. 시청자 참여 유도 방식 (질문 던지기, 공감 유도 등)
5. 결론/마무리 패턴
6. 전체 영상 흐름의 템플릿화
```

**프롬프트 4: 적용 가능한 전략 추출**

```
이 채널의 전략 중 내 채널에 적용할 수 있는 것 3가지를 
구체적으로 제안해주세요.

각 제안에 포함할 내용:
1. 어떤 전략인지 (경쟁 채널에서 관찰된 패턴)
2. 왜 효과적인지 (성공 근거)
3. 내 채널에 어떻게 적용할 수 있는지 (구체적 실행 방안)
4. 적용 시 주의할 점
5. 예상 효과

단순히 "따라하세요"가 아니라, 내 채널의 맥락에 맞게 
변형하는 방법을 구체적으로 알려주세요.
```

### 경쟁 분석 고급 기법: 복수 채널 비교

노트북LM의 진정한 위력은 **여러 채널을 동시에 비교 분석**할 때 드러난다.

```
[복수 채널 비교 분석 프롬프트]

이 노트북에는 3개 채널의 영상이 포함되어 있습니다.
3개 채널의 콘텐츠 전략을 비교 분석해주세요.

1. 각 채널의 고유한 강점은 무엇인가?
2. 3개 채널 모두에서 공통적으로 나타나는 성공 패턴은?
3. 채널별로 차별화된 접근 방식은 무엇인가?
4. 이 3개 채널의 전략을 종합하여, 이상적인 
   콘텐츠 전략 청사진을 만들어주세요.
```

## [바로 실습] 알고리즘을 이기는 디테일 분석법

유튜브 알고리즘은 **클릭률(CTR)**과 **시청 지속율(Retention)**을 가장 중요시한다. 이 두 지표를 높이려면 제목, 썸네일, 도입부, 그리고 영상 전체의 스크립트 구조가 최적화되어야 한다. 노트북LM으로 이 디테일을 분석하는 방법을 살펴보자.

### 분석 프롬프트 — 심층 디테일

**프롬프트 1: 심리학적 트리거 분석**

```
이 영상들의 제목에서 사용된 심리학적 트리거를 분석해주세요.

분석할 트리거 유형:
- 호기심 갭 (Curiosity Gap): "~인 이유", "~의 비밀"
- 긴급성 (Urgency): "지금 당장", "2026년 필수"
- 사회적 증거 (Social Proof): "100만 유튜버가", "전문가 추천"
- 손실 회피 (Loss Aversion): "이걸 모르면 손해", "놓치면 후회"
- 권위 (Authority): "전문가", "10년 경력"
- 구체성 (Specificity): 숫자, 기간, 결과물 명시

각 트리거별로:
1. 해당 트리거를 사용한 영상 제목 나열
2. 각 영상의 성과(가능하다면)
3. 가장 효과적인 트리거 조합 Top 3 제안
```

**프롬프트 2: 영상 길이와 구조 분석**

```
영상 길이와 콘텐츠 구조의 상관관계를 분석해주세요.

분석 항목:
1. 영상 길이 분포 (짧은 영상 vs 긴 영상의 비율)
2. 길이별 콘텐츠 밀도 (분당 정보량 비교)
3. 긴 영상에서 시청자를 잡아두는 기법 (중간 후킹, 예고 등)
4. 짧은 영상의 정보 압축 방식
5. 내 채널의 최적 영상 길이 제안 (주제별)
```

**프롬프트 3: SEO 패턴 분석**

```
영상 제목과 내용에서 SEO 패턴을 분석하고, 
최적화 방안을 제안해주세요.

분석 항목:
1. 제목에 사용된 검색 키워드 패턴
2. 영상 내용(스크립트)에서 반복되는 핵심 키워드
3. 키워드의 자연스러운 배치 방식 (억지스러운 키워드 삽입 vs 자연스러운 포함)
4. 롱테일 키워드 활용 패턴
5. 향후 영상에 적용할 SEO 체크리스트 제안
```

**프롬프트 4: 시청자 유지율 최적화 기법**

```
시청자 유지율을 높이기 위해 사용된 스크립트 기법을 분석해주세요.

다음 기법이 사용되었는지 확인:
1. 오픈 루프 (Open Loop): 결론을 나중에 알려주겠다는 암시
2. 패턴 인터럽트 (Pattern Interrupt): 시청자 예상을 깨는 전환
3. 스토리텔링: 개인 경험이나 사례를 통한 정보 전달
4. 진행 표시기: "첫 번째는~, 두 번째는~" 등 구조 안내
5. 시청자 직접 호명: "여러분", "당신" 등 2인칭 사용
6. 가치 예고: "이 부분이 가장 중요합니다" 등 기대감 조성

각 기법별로 실제 사용 사례를 인용하고, 
효과적인 활용 가이드를 작성해주세요.
```

## [바로 실습] 댓글 민심으로 틈새 찾기

유튜브에서 **블루오션**을 찾는 가장 확실한 방법은 **시청자가 직접 말해주는 것**을 듣는 것이다. 경쟁 채널의 댓글에는 "이런 영상이 없어서 아쉽다", "이 부분을 더 자세히 다뤄주세요"라는 **충족되지 않은 니즈(Unmet Needs)**가 가득하다.

### 소스 준비

```
[틈새 발견용 소스 세팅]
─────────────────────────────────
노트북 이름: "시장 틈새 분석 — [니치 분야명]"

추가할 소스:
1. 내 니치의 인기 채널 3~5개에서 각각
   인기 영상 3~5개의 댓글 데이터
   → 슈퍼유튜브시트로 댓글 수집 후 복사/붙여넣기

2. 내 니치 관련 커뮤니티(네이버 카페, 레딧 등)의 
   자주 묻는 질문 모음 (복사한 텍스트)

3. 내 니치의 최근 트렌드 기사 (웹사이트 URL)
─────────────────────────────────
```

### 분석 프롬프트 — 틈새 시장 발견

**프롬프트 1: 불만과 아쉬움 추출**

```
댓글에서 시청자들이 불만을 표현하거나 아쉬워하는 점을 
모두 찾아주세요.

분석 기준:
1. 직접적 불만 표현 ("아쉽다", "별로", "부족하다" 등)
2. 간접적 불만 (다른 정보 요청, 추가 설명 요구)
3. 비교 불만 ("다른 채널에서는~", "예전 영상이 더~")
4. 기술적 불만 (음질, 화질, 편집 등)

각 불만을 카테고리별로 정리하고, 
빈도 순으로 나열해주세요.
이 불만들을 해소하는 콘텐츠 아이디어도 함께 제안해주세요.
```

**프롬프트 2: 콘텐츠 요청 수집**

```
시청자들이 "이런 영상 만들어주세요"라고 요청한 주제를 
모두 정리해주세요.

수집 기준:
1. 직접 요청 ("~해주세요", "~다뤄주세요", "~만들어주세요")
2. 질문 형태의 간접 요청 ("~는 어떻게 하나요?", "~도 되나요?")
3. 제안 형태 ("~하면 좋겠다", "~하면 대박일 텐데")

요청 주제를 카테고리별로 분류하고,
각 카테고리별 요청 빈도를 표시해주세요.
가장 많이 요청된 주제 Top 10을 순위별로 정리해주세요.
```

**프롬프트 3: 충족되지 않은 니즈 발견**

```
경쟁 채널 댓글에서 충족되지 않은 니즈(unmet needs)를 
찾아주세요.

'충족되지 않은 니즈'란:
- 시청자가 원하지만 아직 누구도 제대로 다루지 않은 주제
- 기존 영상에서 다뤘지만 부족하다고 느끼는 영역
- 여러 시청자가 반복적으로 같은 질문을 하는 영역

분석 결과를 다음 형식으로 정리:
1. 니즈 설명
2. 근거 댓글 인용 (최소 2개)
3. 이 니즈를 충족시킬 영상 아이디어
4. 예상 타깃 시청자 규모 (추정)
```

**프롬프트 4: 블루오션 콘텐츠 아이디어**

```
이 댓글 데이터를 기반으로 블루오션 콘텐츠 아이디어 5개를 
제안해주세요.

각 아이디어에 포함할 내용:
1. 영상 제목 (3가지 안)
2. 타깃 시청자
3. 왜 블루오션인지 (기존에 없거나 부족한 이유)
4. 댓글 데이터에서의 근거
5. 영상 구성안 (도입-본론-결론 요약)
6. 예상 난이도 (제작 관점)
7. 예상 성과 (근거 기반 추정)
```

## [바로 실습] 콘텐츠 다양하게 재가공하기

하나의 영상을 만들었다면, 그 콘텐츠를 **여러 플랫폼과 형태로 재가공(Repurpose)**하는 것이 효율적이다. 노트북LM은 영상 스크립트를 이미 분석한 상태이므로, 다양한 형태로의 변환을 한 번에 요청할 수 있다.

### 분석 프롬프트 — 콘텐츠 재가공

**프롬프트 1: 블로그 포스트 변환**

```
이 영상 스크립트를 블로그 포스트로 변환해주세요.

변환 요구사항:
1. SEO에 최적화된 제목 (H1)
2. 소제목 구조 (H2, H3)
3. 영상에서 말한 내용을 읽기 좋은 글로 재구성
4. 핵심 포인트를 볼드/리스트로 강조
5. 메타 디스크립션 (160자 이내)
6. 블로그 유입을 유튜브로 연결하는 CTA 포함
7. 전체 길이: 2,000~3,000자

영상 특유의 구어체("~거든요", "~잖아요")는 문어체로 변환해주세요.
```

**프롬프트 2: 인스타그램 캐러셀 구성**

```
이 영상의 핵심 내용을 인스타그램 캐러셀 10장으로 
구성해주세요.

각 장(슬라이드)에 포함할 내용:
- 슬라이드 번호
- 메인 텍스트 (20자 이내, 임팩트 있는 한 줄)
- 서브 텍스트 (50자 이내, 보충 설명)
- 시각적 제안 (어떤 아이콘/이미지가 적합한지)

구성:
1장: 표지 (호기심 유발하는 제목)
2~8장: 핵심 내용 (한 슬라이드에 한 포인트)
9장: 요약 정리
10장: CTA (유튜브 영상 링크 유도)

캡션도 함께 작성해주세요. (해시태그 15개 포함)
```

**프롬프트 3: 쇼츠 하이라이트 추천**

```
이 영상에서 쇼츠(Shorts)로 만들 수 있는 하이라이트 구간 
5개를 추천해주세요.

각 추천에 포함할 내용:
1. 해당 구간의 스크립트 내용 (원문 인용)
2. 쇼츠 제목 제안 (3가지 안)
3. 왜 이 구간이 쇼츠에 적합한지
4. 추가 편집 팁 (텍스트 오버레이, 효과음 등)
5. 예상 길이 (30초/45초/60초)

쇼츠에 적합한 기준:
- 독립적으로 이해 가능한 내용
- 임팩트 있는 한 마디 또는 인사이트
- 감정적 반응(놀라움, 공감, 웃음)을 유발하는 부분
- 실용적 팁이 압축된 부분
```

**프롬프트 4: 종합 가이드 영상 기획**

```
이 3개 영상의 내용을 합쳐서 종합 가이드 영상의 
스크립트를 작성해주세요.

요구사항:
1. 3개 영상의 핵심 내용을 하나의 스토리라인으로 통합
2. 중복되는 내용은 제거하고 가장 좋은 설명만 유지
3. 논리적 흐름에 맞게 순서 재배치
4. 새로운 도입부와 결론 작성
5. 각 섹션 사이의 자연스러운 전환 문장 추가
6. 예상 영상 길이: 15~20분
7. 챕터 마커용 타임스탬프 구조 제안
```

### 재가공 워크플로우 자동화

콘텐츠 재가공을 루틴화하면 하나의 영상에서 최소 5개의 콘텐츠를 뽑아낼 수 있다.

```
[1 영상 → 5+ 콘텐츠 재가공 워크플로우]
─────────────────────────────────

원본: 유튜브 영상 1개 (15분)
    │
    ├── 재가공 1: 쇼츠 3~5개 (각 30~60초)
    │   → 프롬프트 3 활용
    │
    ├── 재가공 2: 블로그 포스트 1개
    │   → 프롬프트 1 활용
    │
    ├── 재가공 3: 인스타그램 캐러셀 1세트 (10장)
    │   → 프롬프트 2 활용
    │
    ├── 재가공 4: 트위터/X 스레드 1개 (10트윗)
    │   → "이 영상의 핵심을 10개 트윗 스레드로 변환" 프롬프트
    │
    └── 재가공 5: 뉴스레터 콘텐츠 1개
        → "이 영상을 이메일 뉴스레터 형태로 변환" 프롬프트

결과: 1개 영상으로 최소 7~10개 콘텐츠 생산
─────────────────────────────────
```

## 콘텐츠 제작 루틴 만들기

지금까지 배운 모든 도구와 기법을 **주간 루틴**으로 통합하자. 이 루틴을 따르면 콘텐츠 기획에서 업로드, 분석까지 체계적으로 진행할 수 있다.

### 주간 콘텐츠 제작 루틴

```
[데이터 드리븐 유튜브 주간 루틴]
═══════════════════════════════════════════

📅 월요일: 트렌드 검색 + 아이디어 발굴
─────────────────────────────────
오전: 슈퍼유튜브시트
  · 키워드 검색 기능으로 이번 주 트렌드 키워드 50개 수집
  · 트렌드 영상의 조회수/참여율 데이터 확인
  · 골든 키워드(높은 검색량 + 낮은 경쟁) 5개 선별

오후: 노트북LM
  · 트렌드 영상 10개를 소스로 추가
  · "이번 주 트렌드 중 내 채널에 적합한 주제 3가지" 분석
  · 오디오 오버뷰로 트렌드 브리핑 생성 (이동 시간에 청취)

산출물: 이번 주 콘텐츠 후보 주제 5개


📅 화요일: 경쟁 분석 + 벤치마킹
─────────────────────────────────
오전: 슈퍼유튜브시트
  · 경쟁 채널 3개의 최근 영상 데이터 수집
  · 벤치마킹 보고서 자동 생성
  · 경쟁 채널의 성공 영상 패턴 확인

오후: 노트북LM
  · 경쟁 채널 인기 영상 5~10개를 소스로 추가
  · "경쟁 채널의 전략 역설계" 프롬프트 실행
  · 내 채널에 적용할 수 있는 전략 3가지 추출

산출물: 경쟁 분석 인사이트 + 적용 전략


📅 수요일: 콘텐츠 기획 + 스크립트 초안
─────────────────────────────────
오전: 노트북LM
  · 월~화 분석 결과를 종합하여 이번 주 영상 주제 확정

## 저작권 및 한계 이해하기

노트북LM은 강력한 도구이지만, 한계와 주의사항을 명확히 알고 사용해야 한다.

### 노트북LM의 기술적 한계

```
[알아야 할 한계 사항]
─────────────────────────────────

1. 소스 그라운딩의 양날의 검
   장점: 업로드한 소스에서만 답하므로 환각이 적다
   한계: 소스에 없는 정보는 절대 제공하지 않는다
   → 대응: 충분하고 다양한 소스를 추가할 것

2. YouTube 자막 품질 의존
   · 자동 생성 한국어 자막: 80~90% 정확도 (2026년 기준)
   · 전문 용어, 고유명사는 오인식될 수 있음
   · 배경 음악이나 효과음이 큰 영상은 자막 품질 저하
   → 대응: 중요한 분석은 자막 내용을 직접 확인할 것

3. 정량적 분석의 한계
   · 조회수, 좋아요 수 등 수치 데이터는 소스에 
     텍스트로 포함된 경우에만 분석 가능
   · 유튜브 스튜디오의 상세 통계(CTR, 시청 지속율 등)는 
     직접 데이터를 제공해야 분석 가능
   → 대응: 슈퍼유튜브시트의 정량 데이터를 
     복사/붙여넣기로 소스에 포함시킬 것

4. 실시간 데이터 미반영
   · 소스를 추가한 시점의 정보만 분석
   · 추가 이후의 변화(새 댓글, 조회수 변화)는 반영 안 됨
   → 대응: 주기적으로 소스를 업데이트할 것

5. 노트북당 소스 50개 제한
   · 대규모 분석 시 노트북을 여러 개로 분리해야 함
   · 노트북 간 교차 분석은 불가
   → 대응: 목적별 노트북 분리 + 핵심 소스만 선별
─────────────────────────────────
```

### 경쟁 분석의 저작권 고려

경쟁 채널의 영상을 분석하는 것 자체는 일반적으로 **공정 이용(Fair Use)**의 범위에 해당한다. 다만 주의할 점이 있다.

```
[경쟁 분석 저작권 가이드라인]
─────────────────────────────────

✅ 허용되는 것:
  · 공개된 영상의 전략적 패턴 분석
  · 제목, 구조, 키워드 등의 전략 벤치마킹
  · 분석 결과를 자신의 전략 수립에 참고

❌ 주의해야 할 것:
  · 경쟁자의 스크립트를 그대로 복사하여 사용
  · 분석 결과를 그대로 공개 게시 (비교 영상 등에서)
  · 타인의 댓글을 작성자 동의 없이 공개적으로 인용

💡 원칙:
  "분석은 자유, 복제는 금지"
  경쟁자의 전략을 이해하고 영감을 얻되,
  실행은 반드시 자신만의 방식으로 해야 한다.
─────────────────────────────────
```

## 상황별 질문 템플릿

노트북LM을 실전에서 바로 활용할 수 있도록, 상황별 프롬프트 템플릿을 총정리한다. 이 템플릿들을 복사하여 자신의 상황에 맞게 수정해서 사용하면 된다.

### 1) 채널 성장 분석 (5가지)

```
① "내 채널의 최근 3개월간 콘텐츠 방향이 어떻게 변화했는지 
   분석해주세요. 주제, 톤, 영상 길이의 변화 추이를 정리하고, 
   이 변화가 긍정적인지 부정적인지 평가해주세요."

② "내 영상 중 '바이럴 잠재력'이 가장 높은 영상 3개를 
   선택하고, 그 이유를 분석해주세요. 또한 이 영상들의 
   공통점을 기반으로 바이럴을 노릴 수 있는 새로운 영상 
   아이디어 3개를 제안해주세요."

③ "내 채널의 콘텐츠를 카테고리별로 분류하고, 각 카테고리의 
   성과(조회수, 참여도)를 비교해주세요. 집중해야 할 
   카테고리와 축소하거나 포기해야 할 카테고리를 제안해주세요."

④ "내 영상의 제목과 내용의 일치도를 분석해주세요. 
   제목에서 약속한 내용을 실제로 영상에서 충실히 다루고 
   있는지, 클릭베이트에 해당하는 사례는 없는지 점검해주세요."

⑤ "내 채널의 브랜딩 일관성을 분석해주세요. 영상마다 
   반복되는 캐치프레이즈, 인트로/아웃트로 패턴, 말투, 
   핵심 메시지가 일관적인지 확인하고, 브랜딩 강화를 위한 
   제안을 해주세요."
```

### 2) 콘텐츠 기획 (5가지)

```
① "이 소스들의 내용을 기반으로, 향후 4주간 업로드할 
   영상 8개(주 2회)의 콘텐츠 캘린더를 만들어주세요. 
   각 영상의 제목, 핵심 키워드, 타깃 시청자, 
   예상 길이를 포함해주세요."

② "내 인기 영상 Top 5의 후속편(시즌 2)을 기획해주세요. 
   원본 영상에서 다루지 않았거나 더 깊이 다룰 수 있는 
   주제를 찾아 각각의 영상 기획안을 작성해주세요."

③ "이 소스들에서 '시리즈물'로 만들 수 있는 
   콘텐츠 시리즈 3가지를 제안해주세요. 각 시리즈는 
   최소 5편으로 구성하고, 에피소드별 주제와 순서를 
   정해주세요."

④ "내 기존 영상 내용을 합쳐서 만들 수 있는 
   '완전 정복 가이드' 영상의 기획안을 작성해주세요. 
   어떤 영상들의 어떤 내용을 어떤 순서로 조합할지 
   구체적으로 제안해주세요."

⑤ "현재 소스에서 다루고 있는 주제와 관련된 
   '초보자 FAQ 영상'을 기획해주세요. 시청자가 
   가장 궁금해할 질문 10개를 뽑고, 각 질문에 대한 
   핵심 답변 요약을 작성해주세요."
```

### 3) SEO 최적화 (5가지)

```
① "이 영상들의 제목에 사용된 키워드를 모두 추출하고, 
   키워드 빈도 순위를 정리해주세요. 과도하게 사용되어 
   식상해진 키워드와 더 활용해야 할 키워드를 
   구분해주세요."

② "이 영상들의 내용을 분석하여 잠재적 롱테일 키워드 
   20개를 추출해주세요. 각 키워드에 대해 적합한 
   영상 제목 예시도 함께 만들어주세요."

③ "내 영상들의 설명문 패턴을 분석하고, SEO에 최적화된 
   영상 설명문 템플릿을 만들어주세요. 키워드 배치 위치, 
   링크 구성, CTA 위치 등을 포함해주세요."

④ "경쟁 채널과 내 채널의 제목 키워드를 비교해서, 
   내가 놓치고 있는 키워드(키워드 갭)를 찾아주세요. 
   그 키워드를 활용한 영상 제목 5개를 제안해주세요."

⑤ "이 영상들의 제목을 A/B 테스트 관점에서 분석해주세요. 
   현재 제목의 장단점을 지적하고, 각 영상별로

```

### 4) 경쟁 분석 (5가지)

```
① "이 경쟁 채널의 콘텐츠를 시간순으로 분석하여

② "이 경쟁 채널이 사용하는 시청자 유지 기법을

③ "경쟁 채널 3개의 '실패한 영상'(반응이 저조한 영상)을

## 해외 실전 활용 사례

데이터 기반 유튜브 운영은 한국에서만의 트렌드가 아니다. 세계적으로 성공한 유튜버와 컨설턴트들도 비슷한 접근법을 사용하고 있다. 이들의 방법론을 노트북LM + 슈퍼유튜브시트로 어떻게 재현할 수 있는지 살펴보자.

### 사례 1: MrBeast의 데이터 드리븐 제목 테스트

구독자 3억 명을 넘긴 MrBeast(지미 도널드슨)는 유튜브 역사상 가장 성공한 크리에이터 중 하나다. 그의 성공 뒤에는 **철저한 데이터 분석**이 있다.

MrBeast의 알려진 방법론 중 하나는 **제목과 썸네일의 사전 테스트**다. 영상을 업로드하기 전에 다양한 제목과 썸네일 조합을 만들어놓고, 팀 내부에서 어떤 조합이 가장 클릭하고 싶은지를 테스트한다. 업로드 후에도 데이터를 보면서 제목과 썸네일을 수시로 변경한다. 그는 인터뷰에서 이렇게 말한 바 있다.

> "나는 같은 영상의 제목을 10~20번 바꿀 때도 있다. 데이터가 말해주는 것을 따르는 것이다."

**노트북LM + 슈퍼유튜브시트로 재현하는 법:**

```
[MrBeast식 제목 테스트 워크플로우]
─────────────────────────────────

STEP 1: 데이터 수집 (슈퍼유튜브시트)
  · 내 니치의 상위 영상 50개 제목 + 조회수 수집
  · 검색 키워드별 상위 노출 제목 패턴 분석

STEP 2: 패턴 분석 (노트북LM)
  · 수집한 제목 데이터를 소스로 추가
  · 프롬프트: "조회수 상위 10% 영상의 제목 공통 패턴을 
    분석하고, 그 패턴을 적용한 새로운 제목 10개를 
    만들어주세요."

STEP 3: 제목 후보 생성
  · 노트북LM의 분석 기반으로 제목 후보 5~10개 생성
  · 각 후보에 사용된 심리학적 트리거 확인

STEP 4: 업로드 후 추적 (슈퍼유튜브시트)
  · 제목 변경 전후의 CTR 변화 자동 추적
  · 최적 제목 확정 후 인사이트 기록
─────────────────────────────────
```

### 사례 2: Paddy Galloway의 유튜브 전략 컨설팅

패디 갤러웨이(Paddy Galloway)는 세계적인 유튜브 전략 컨설턴트로, MrBeast를 포함한 대형 유튜버들에게 채널 성장 전략을 컨설팅한다. 그의 분석 방법론의 핵심은 **채널의 모든 영상을 스프레드시트에 정리하고 패턴을 찾는 것**이다.

Paddy Galloway의 공개된 분석 프레임워크는 다음과 같다.

```
[Paddy Galloway의 분석 프레임워크]
─────────────────────────────────

1. Title Score (제목 점수)
   → 제목의 클릭 유도력을 1~10으로 채점
   → 기준: 호기심, 명확성, 감정적 트리거, 키워드

2. Thumbnail Score (썸네일 점수)
   → 썸네일의 시각적 임팩트를 1~10으로 채점
   → 기준: 대비, 감정 표현, 텍스트 가독성

3. Topic Score (주제 점수)
   → 주제의 시장성을 1~10으로 채점
   → 기준: 검색량, 트렌드, 타깃 관심도

4. Packaging Score (패키징 종합 점수)
   → 위 3가지의 종합 점수
   → 이 점수와 실제 조회수의 상관관계 분석
─────────────────────────────────
```

**노트북LM + 슈퍼유튜브시트로 재현하는 법:**

```
[Paddy Galloway식 분석 워크플로우]
─────────────────────────────────

STEP 1: 전 영상 데이터 수집 (슈퍼유튜브시트)
  · 경쟁 채널의 모든 영상(또는 최근 100개) 데이터 수집
  · 제목, 조회수, 업로드일, 영상 길이 자동 수집

STEP 2: 스코어링 (노트북LM)
  · 수집 데이터를 소스로 추가
  · 프롬프트: "각 영상의 제목을 다음 기준으로 1~10점 
    채점해주세요. 기준: 호기심 유발(1~10), 명확성(1~10), 
    감정적 트리거(1~10), 키워드 적합성(1~10). 
    표 형식으로 정리해주세요."

STEP 3: 상관관계 분석
  · 프롬프트: "제목 점수가 높은 영상과 조회수의 
    상관관계를 분석해주세요. 점수가 높지만 조회수가 
    낮은 영상이 있다면, 그 이유를 추론해주세요."

STEP 4: 인사이트 적용
  · 다음 영상의 제목/썸네일/주제에 분석 결과 반영
─────────────────────────────────
```

### 사례 3: vidIQ의 자체 콘텐츠 전략

vidIQ는 유튜브 분석 도구를 만드는 회사이면서 동시에 **130만 구독자를 가진 유튜브 채널**을 운영한다. 그들은 자사 도구로 수집한 데이터를 기반으로 콘텐츠를 만드는 **메타 전략**을 사용한다.

vidIQ 채널의 핵심 전략은 다음과 같다.

```
[vidIQ의 콘텐츠 전략]
─────────────────────────────────

1. 키워드 기반 주제 선정
   → 자사 도구로 검색량이 높고 경쟁이 낮은 키워드 발굴
   → 그 키워드를 중심으로 영상 제작

2. 트렌드 연동 콘텐츠
   → 유튜브 알고리즘 업데이트, 새 기능 출시 등
     플랫폼 자체의 변화를 빠르게 다룸
   → "유튜브가 방금 바꾼 것" 류의 긴급성 콘텐츠

3. 데이터 시각화 콘텐츠
   → 실제 데이터와 차트를 영상에 직접 보여줌
   → 일반적 조언 대신 수치 기반의 구체적 가이드

4. 커뮤니티 피드백 루프
   → 댓글에서 다음 영상 주제를 직접 수집
   → "가장 많이 요청된 주제" 시리즈 운영
─────────────────────────────────
```

**노트북LM + 슈퍼유튜브시트로 재현하는 법:**

```
STEP 1: 키워드 발굴 (슈퍼유튜브시트)
  · 내 니치의 관련 키워드 100개 자동 수집
  · 검색량 대비 경쟁 영상 수 분석
  · 골든 키워드 선별

STEP 2: 트렌드 기반 기획 (노트북LM)
  · 트렌드 영상 + 뉴스 기사를 소스로 추가
  · "이 트렌드를 내 채널의 관점에서 다루는 영상 기획안" 생성

STEP 3: 커뮤니티 피드백 수집 (슈퍼유튜브시트 → 노트북LM)
  · 댓글 데이터 수집 → 노트북LM에서 요청 주제 분석
  · 가장 많이 요청된 주제를 다음 영상 기획에 반영
```

### 사례 4: Think Media의 체계적 키워드 리서치

싱크 미디어(Think Media)는 유튜브 성장 교육 분야에서 300만 이상의 구독자를 보유한 채널이다. 설립자 숀 카넬(Sean Cannell)은 **키워드 리서치의 체계화**로 유명하다.

Think Media의 키워드 리서치 프로세스는 다음과 같다.

```
[Think Media의 키워드 리서치 프로세스]
─────────────────────────────────

1. Seed Keywords (씨앗 키워드)
   → 내 니치의 핵심 주제 10~20개를 나열

2. YouTube Suggest (유튜브 자동완성)
   → 각 씨앗 키워드를 유튜브 검색창에 입력
   → 자동완성으로 나타나는 롱테일 키워드 수집

3. Competitor Keywords (경쟁자 키워드)
   → 경쟁 채널의 인기 영상 제목에서 키워드 추출

4. Keyword Scoring (키워드 채점)
   → 검색량, 경쟁 수준, 내 채널 적합도를 기준으로 채점
   → 최고 점수 키워드를 우선 제작

5. Content Calendar (콘텐츠 캘린더)
   → 채점 결과를 기반으로 월간 콘텐츠 캘린더 작성
─────────────────────────────────
```

**노트북LM + 슈퍼유튜브시트로 재현하는 법:**

```
STEP 1: 씨앗 키워드 확장 (슈퍼유튜브시트)
  · 씨앗 키워드 입력 → 자동으로 관련 키워드 200개 수집
  · 각 키워드의 경쟁 영상 수, 상위 영상 평균 조회수 자동 수집

STEP 2: 경쟁자 키워드 추출 (슈퍼유튜브시트 → 노트북LM)
  · 경쟁 채널 영상 제목 데이터를 노트북LM에 추가
  · 프롬프트: "이 제목들에서 반복적으로 사용되는 
    키워드를 빈도순으로 정리하고, 내 채널에서 아직 
    다루지 않은 키워드를 표시해주세요."

STEP 3: 키워드 채점 및 캘린더 (노트북LM)
  · 프롬프트: "수집된 키워드 데이터를 기반으로 
    다음 4주간의 콘텐츠 캘린더를 만들어주세요. 
    검색량이 높고 경쟁이 낮은 키워드를 우선 배치하고, 
    각 키워드에 적합한 영상 제목과 포맷을 제안해주세요."
```

### 해외 사례의 공통점

이 네 가지 사례에서 발견되는 공통점을 정리하면 다음과 같다.

```
[세계적 유튜버들의 공통 방법론]
─────────────────────────────────

1. 감이 아닌 데이터로 의사결정
   → 모든 결정(주제, 제목, 업로드 시점)에 데이터 근거

2. 체계적인 경쟁 분석
   → 경쟁자를 무시하거나 막연히 의식하는 것이 아닌,
     구조적으로 분석하고 전략을 역설계

3. 반복 가능한 프로세스
   → 성공을 한 번의 운이 아닌 반복 가능한 시스템으로 전환

4. 피드백 루프
   → 데이터 수집 → 분석 → 실행 → 측정의 순환 구조

5. 도구의 전략적 활용
   → 도구에 의존하는 것이 아닌, 도구를 전략에 맞게 활용
─────────────────────────────────

이 모든 것을 슈퍼유튜브시트(데이터 수집) + 노트북LM(데이터 분석)
조합으로 무료로 구현할 수 있다.
─────────────────────────────────
```

## 핵심 정리

이 장에서 다룬 모든 내용을 최종 정리한다.

```
[Chapter 13 핵심 정리]
═══════════════════════════════════════════

1. 내 채널 분석: 콘텐츠 패턴, SWOT, 도입부 분석
   → 내 영상 20~25개를 소스로 추가하여 심층 분석
   → 성공 패턴과 실패 패턴을 객관적으로 파악

2. 팬덤 이해: 댓글 데이터 기반 시청자 분석
   → 슈퍼유튜브시트에서 수집한 댓글을 노트북LM으로 분석
   → 시청자 페르소나 생성으로 타깃 명확화

3. 경쟁 분석: 전략 역설계
   → 경쟁 채널의 인기 영상을 소스로 추가
   → 콘텐츠 전략, 스크립트 구조, 시리즈 포맷 분석

4. 디테일 분석: 심리학적 트리거, SEO, 유지율
   → 클릭률과 시청 지속율을 높이는 구체적 기법 도출

5. 틈새 찾기: 댓글 민심에서 블루오션 발견
   → 경쟁 채널 댓글의 충족되지 않은 니즈 포착

6. 콘텐츠 재가공: 1영상 → 7~10개 콘텐츠
   → 블로그, 인스타그램, 쇼츠, 뉴스레터로 다각적 활용

7. 주간 루틴: 월~일 체계적 워크플로우
   → 데이터 수집 → 분석 → 기획 → 제작 → 측정 순환

8. 상황별 프롬프트 템플릿: 25개 즉시 활용 가능
   → 채널 성장, 콘텐츠 기획, SEO, 경쟁 분석, 팬 분석

9. 해외 사례: MrBeast, Paddy Galloway, vidIQ, Think Media
   → 세계적 유튜버들의 방법론을 무료 도구로 재현

═══════════════════════════════════════════
```

노트북LM은 단순한 AI 챗봇이 아니다. **내 데이터를 기반으로 사고하는 리서치 파트너**다. 슈퍼유튜브시트가 데이터를 모아주고, 노트북LM이 그 데이터에서 인사이트를 뽑아주고, 당신은 그 인사이트를 실행에 옮긴다. 이 삼박자가 맞아떨어지면, 더 이상 감에 의존하는 유튜브 운영에서 벗어나 **데이터가 증명하는 성장**을 경험하게 될 것이다.
