## 2. LLM·집필 도구

### ChatGPT (OpenAI)
- **모델**: GPT-5 계열 체제. 2026년 2월 GPT-4o/4.1/o4-mini 등 구모델 퇴역. 최신 프론티어 모델은 유료 전용. (서드파티 출처 간 명칭 불일치 있음 `[요확인: 공식 릴리스 노트]`)
- **Projects**: 유지. Plus는 프로젝트당 파일 25개 제한 → 장편 자료 관리에는 빡빡.
- **Canvas**: 별도 사이드 패널 제거(2026.5), 채팅 내 인라인 편집으로 통합 `[요확인]`.
- **Tasks**: 예약·반복 실행 유지 (Plus 이상).
- **Deep Research**: MCP·외부 앱 연결, 신뢰 사이트 제한, 중간 개입 지원(2026.2). 무료 5회/월, Plus 10회/월.
- **커스텀 GPT**: 유지, 무료 티어는 생성 불가.
- **요금** `[요확인]`: Free $0(광고 도입) / Go $8 / Plus $20 / Pro $100·$200 / Business ~$25/seat.
- **집필 관점**: 리서치·아이디어·커스텀 도우미에 강함. 파일 단위 원고 관리·git·일괄 수정에는 구조적으로 약함.

### Claude (Anthropic)
- **모델**: Sonnet 5(2026.6, 무료·Pro 기본) / Opus 4.8(2026.5) / Fable 5(2026.6, 최상위) / Haiku 4.5.
- **Artifacts·Projects**: 유지·강화. Pro 이상 Projects 무제한 + retrieval → 장편 자료 관리에 ChatGPT보다 유리.
- **Cowork**: 비개발자용 에이전트 워크스페이스. 데스크톱(2026.1) → Windows(2.10) → 웹·모바일(7.7) 확장.
- **Routines**: 예약 자동화(정기 교정 패스 등).
- **요금**: Free $0 / Pro $20(연결제 $17, **Claude Code·Cowork 포함**) / Max $100·$200 / Team $20~125/seat.

### Claude Code ★ 신설 파트의 근거
- **실행 환경**: 터미널 CLI, **데스크톱 앱**(비개발자 권장 진입점), 웹·모바일·Slack, VS Code/JetBrains 확장.
- **비코딩 사용 다수화**: 비즈니스 프로세스 용도가 개발 용도를 추월했다는 통계 보고.
- **작가 활용 4대 축** (책 4부의 뼈대):
  1. 긴 원고 집필 — 챕터별 마크다운 파일로 직접 작성·수정
  2. git 버전 관리 — "어제 버전으로 되돌려줘"를 자연어로
  3. 다중 파일 일괄 수정 — 전권 용어 통일·표기 교정을 한 문장으로
  4. 반복 작업 자동화 — Skills(교정 체크리스트 패키징) + Routines(주간 교정 패스)
- **요금**: 별도 구독 아님. Claude Pro $20/월에 포함 → 진입 장벽 낮음.
- 참고 사례: Claude Code Novel Writer(오픈소스), 비개발자 자동화 사례 다수.

## 3. 리서치·시각화 도구

### NotebookLM (Google) — 비중 확대
- Studio 대폭 강화: 오디오 오버뷰(**한국어 지원**, 대화형 모드), 비디오 오버뷰(80개 언어), 마인드맵, 인포그래픽, 데이터 테이블, 퀴즈.
- 소스당 50만 단어/200MB. 소스 기반 답변으로 환각 억제 → 집필 리서치의 중심 도구.
- 요금: Free $0(소스 50개) / Plus $7.99(100개) / Pro $19.99(300개) / Ultra $99.99+.
- 활용: 자료 리서치·개요, 원고를 오디오로 만들어 "귀로 퇴고", 마인드맵으로 목차 설계.

### Napkin AI — 유지
- 정상 운영·성장(사용자 500만+). 텍스트→다이어그램·인포그래픽. **SVG 내보내기 = 인쇄 품질** → 종이책 도판에 적합.
- 요금: Free(주 500크레딧) / Pro ~$12/월.

### Genspark — 교체 권장
- AI 슈퍼 에이전트로 전환(ARR $200M). 팩트체크 단일 용도로는 과하고 크레딧·레이트리밋 부담, 사용자 평가 양극화.
- **책에서는 Perplexity로 교체**: 인용 기반 리서치 표준, Pro $20/월. 단 "인용도 원출처 직접 확인" 원칙 필수(인용 조작 사례 연구 존재).

### Whimsical — 유지
- 정상 운영. 자연어→플로우차트/마인드맵 강화. Free(AI 100회) / Pro $12/월.

### STT (녹취 → 글감)
- **클로바노트**: 무료 월 300~600분, 요약 편의. 유튜브 URL 미지원.
- **다글로**: 앱 녹음 무제한 무료, 유튜브 URL 변환 지원, 무제한 월 ₩11,900부터. 전문용어에 강함.
- 티로(Tiro)·Vrew·Whisper 등 병기 가능.

### 이미지 생성 (삽화)

## 5. 마케팅·자동화

### litt.ly (리틀리)
- 링크인바이오 → 수익화 플랫폼으로 확장. 무료 플랜에 전자책 판매·월 100건 이메일·알림톡 포함. 판매 수수료 1~5%.
- 요금: Free / 프로 ₩2,450/월(연결제 할인가, 정가 ₩4,900) / 브랜드 ₩9,450/월.

### Maily (메일리) vs 스티비
- **메일리**: 개인 창작자 무료 + 유료 멤버십·개별 판매·후원 수익화 내장 → 시작점으로 추천.
- **스티비**: 구독자 기반 과금(1,000명 기준 스탠다드 ~₩27,000/월). 자동화·세분화 강함 → 리스트 성장 후 병행/이전.

### Metricool 외 SNS 자동화
- **Metricool**: 운영 중. AI 예약 발행(Advanced 이상). Free 플랜에 LinkedIn·X 미포함, X는 €5 애드온. Starter $22/월.
- 대안: Buffer(심플·무료), Publer(가성비), SocialBee(에버그린 재활용), 국내 — 피드팡·스마트포스트·Posty·Mirra(한글 카드뉴스+쓰레드 자동화).

### Google Apps Script
- 여전히 무료. **2026.6 Workspace Core Service 승격**, Gemini 사이드패널로 자연어 코드 생성 → 비개발자 접근성 대폭 개선.
- Gmail 발송 한도: 일반 ~500통/일. 대안: Make/Zapier(노코드), n8n(오픈소스).
- 책에서는: 강의의 5차시 분량 Apps Script 심화는 축소하고, **Claude Code 자동화(4부) + Gemini 자연어 생성**으로 대체 서술.

### OSMU (원소스멀티유즈)
- 공식: 원고 1챕터 → 카드뉴스 + 쓰레드 5~7개 + 릴스 대본 + 뉴스레터 요약.
- 도구: Claude/ChatGPT/NotebookLM(재가공) + Mirra/Canva(비주얼) + Metricool/피드팡(발행).
- 쓰레드 공식 API 개방으로 예약·자동 포스팅 합법화 → "AI 초안 + 사람 검수" 원칙.
