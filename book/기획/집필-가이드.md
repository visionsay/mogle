# 집필 가이드 (모든 챕터 공통)

## 독자와 화자

- 저자: 송아영 (전자책 출판 스터디 리더, 기업 생성형 AI 교육 강사)
- 독자: AI를 잘 모르는 직장인·전문가·예비 작가. "퇴근 후 30분"이 현실인 사람.
- 화자는 1인칭 저자 시점. 수강생·교육생을 지도한 경험자의 목소리.

## 문체

- 경어체: "~합니다 / ~하세요 / ~해 보세요". 친근하되 단정하게.
- 한 문단 3~5문장. 짧은 문장 위주. 번역투·과장 금지.
- 도구 이름은 첫 등장 시 한글(영문) 병기: 노트북LM(NotebookLM). 이후 자유롭게.
- 독자를 "여러분"이라 부른다.

## 챕터 구성 템플릿

1. **도입 (2~4문단)**: 독자가 겪는 문제 상황 → 이 장이 해결할 것 한 줄 약속
2. **본문 섹션들**: 목차의 절 단위. 원리 설명 → 도구 적용 → 실습 순서
3. **프롬프트 박스**: 복사해 쓸 수 있는 완성형 프롬프트. 코드블록으로 표기하고 `[대괄호]`로 변수 표시
4. **오늘의 30분 실습**: 장 끝에 실습 과제 3~5개 (체크박스 목록)
5. **이 장의 산출물**: 실습을 마치면 손에 남는 결과물 명시

## 사실성 원칙 (중요)

- 도구의 기능·요금은 `book/기획/도구-최신화-리서치.md`의 조사 결과만 사용한다. 임의로 지어내지 않는다.
- 리서치 보고서에 `[요확인]` 표시가 있는 수치는 본문에서도 각주 스타일로 "(2026년 7월 기준, 최신 정보는 공식 페이지 확인)"을 붙인다.
- **저자 개인 일화·수강생 사례가 필요한 자리는 지어내지 말고 `[저자 사례: 어떤 내용이 들어가면 좋은지 한 줄 설명]` 플레이스홀더로 남긴다.** 저자가 직접 채운다.
- 통계·연구 수치는 출처를 아는 것만 쓰고, 모호하면 "~하는 경우가 많습니다" 수준으로 서술한다.
- 스크린샷이 들어갈 자리는 `[그림: 설명]`으로 표시한다.

## 파일 규칙

- 위치: `book/원고/`
- 파일명: `00-프롤로그.md`, `01-1부-1장-내-경험을-책의-재료로.md` 형식 (숫자 2자리-부-장-제목)
- 각 파일 첫 줄: `# n장. 제목` (프롤로그는 `# 프롤로그 — 제목`)
- 분량: 장당 한글 기준 6,000~9,000자(공백 포함) 목표. 프롤로그는 3,000~4,000자.

## 금지 사항

- 패스트캠퍼스 강의 영상 대사를 그대로 옮기지 않는다 (커리큘럼 구조만 참고).
- 특정 모델 버전명에 과도하게 의존하는 서술 금지 — "버전은 바뀌어도 원리는 남는다" 관점으로.
- 근거 없는 수익 보장 표현 금지 ("무조건", "누구나 월 천만 원" 류).
