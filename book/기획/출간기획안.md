# 출간 기획안 (초안)

> 작성일: 2026-07-18 · 상태: 초안 — 도구 최신화 리서치 반영 후 확정

## 1. 기획 배경

- 원천 콘텐츠: 패스트캠퍼스 온라인 강의 「하루 30분이면 끝! AI로 완성하는 전자책 제작부터 수익화까지」 (송아영, 총 17시간 24분, 6개 파트)
- 저자가 강의를 직접 재구성하는 단행본. 강의 목차를 그대로 옮기지 않고, 종이책 독자에 맞게 재설계한다.
- 강의 제작 시점(2025) 이후 AI 도구 환경이 크게 바뀌었으므로, 2026년 기준으로 도구·기능·요금을 전면 최신화한다.
- 강의에 없던 **Claude Code 활용 파트를 신설**한다. (필수 요구사항)

## 2. 콘셉트

- **주제와 출간 형태의 구분 (중요)**:
  - 책이 다루는 **주제 = 전자책 제작부터 수익화까지** (강의와 동일)
  - 이 책 자체의 **출간 형태 = 종이책 단행본** (전자책 노하우를 종이책으로 출판)
- 가제(후보):
  1. 『하루 30분, AI로 전자책 쓰기』 — 30일 완성 실전 로드맵
  2. 『AI 전자책 수익화의 기술』
  3. 『퇴근 후 30분, 전자책으로 월급 밖 수익 만들기』
- 한 줄 콘셉트: "직장인·전문가가 하루 30분씩 30일 만에, AI와 함께 전자책을 기획→집필→출간→수익화까지 끝내는 실전 매뉴얼"
- 형태: 종이책 단행본 (신국판 예상, 250~320쪽 목표), 실습 스크린샷·프롬프트 예시 다수 포함

## 3. 타깃 독자

- 1순위: 자기 전문성을 책으로 정리해 퍼스널 브랜딩·부수입을 만들고 싶은 직장인/프리랜서/강사
- 2순위: 전자책·독립출판에 도전했다가 완주하지 못한 예비 작가
- 3순위: AI 글쓰기 도구를 업무에 도입하려는 실무자

## 4. 차별점

1. **완주 시스템**: 도구 나열이 아니라 "30일 루틴 + 산출물 체크리스트"로 실제 탈고까지 끌고 가는 실행 설계
2. **2026년 최신 도구 반영**: ChatGPT·Claude·NotebookLM 등 주요 도구의 현행 기능 기준으로 전면 재집필
3. **Claude Code 파트**: 개발자 도구로 알려진 Claude Code를 '작가의 집필 스튜디오'로 쓰는 국내 최초 수준의 단행본 가이드 (원고 버전 관리, 전권 일괄 퇴고, 반복 작업 자동화)
4. **수익화까지**: 출간이 끝이 아니라 시작 — 출간 후 3개월 운영과 수익 파이프라인 설계까지 다룸
5. 저자의 실전 이력: 전자책 출판 스터디 리더, 기업 AI 교육(SKT·SK이노베이션·식약처 등) 경험 기반의 검증된 노하우

## 6. 집필 원칙

- 모든 도구 설명은 집필 시점 실측 기준(기능·화면·요금)으로 쓰고, 버전 변화에 견디도록 "원리 → 도구 적용" 순서로 서술한다.
- 프롬프트는 복사해 바로 쓸 수 있는 완성형으로 수록하고, 변수 부분을 명시한다.
- 각 챕터 끝에 "오늘의 30분 실습"과 산출물 체크리스트를 둔다.
