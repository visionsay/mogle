# 부록 A. 이 책의 프롬프트 전체 모음

본문에 실린 프롬프트를 장 순서대로 모두 모았습니다. `[대괄호]` 부분만 여러분의 상황으로 바꿔 그대로 복사해 쓰세요. 각 프롬프트 위의 한 줄이 "어느 장, 어떤 용도"인지 알려 줍니다.

---

## 1부. 기획 (1~3장)

### A-1. 전문성 발굴 인터뷰
> 1장 · AI에게 답이 아니라 질문을 시켜, 10분 인터뷰로 내 경험 자산과 주제 후보 5개를 캐낼 때

```
당신은 15년 경력의 출판 기획자입니다. 저는 제 경험을 바탕으로 전자책을 쓰려고 합니다.
지금부터 저를 인터뷰해서 책의 재료가 될 전문성과 경험을 발굴해 주세요.

[저에 대한 기본 정보]
- 직업/경력: [예: 12년 차 유통회사 MD]
- 부업/취미/특이 경험: [예: 주말 스마트스토어 운영 3년]
- 사람들이 나에게 자주 물어보는 것: [예: 상품 사진 찍는 법, 위탁 판매 시작법]

[인터뷰 규칙]
1. 질문은 반드시 한 번에 하나씩만 하세요.
2. 제 답변을 들은 뒤, 더 깊이 파고드는 후속 질문을 하세요.
3. 추상적인 답변이 나오면 "구체적인 사례나 숫자"를 요청하세요.
4. 총 10개 질문 후, 제 답변을 다음 형식으로 정리하세요:
   ① 핵심 전문 분야 3가지 ② 남보다 잘 아는 구체적 문제 5가지
   ③ 실패와 시행착오 경험 3가지 ④ 책 주제 후보 5가지(가제 포함)
```

### A-2. 독자 페르소나 3종 + 독자 질문 20개
> 1장 · 인터뷰에 이어 같은 채팅방에서, 책이 답해야 할 "독자 질문 20개"까지 뽑을 때

```
위 인터뷰 내용을 바탕으로, 제 책 주제 후보 중 [선택한 주제]에 대한
독자 페르소나 3종(핵심 독자/인접 독자/잠재 독자)을 만들어 주세요.

각 페르소나마다 다음을 포함하세요:
1. 이름, 나이, 직업, 하루 일과 요약
2. 이 주제와 관련해 겪는 구체적인 고통 3가지
3. 이미 시도해 봤지만 실패한 방법
4. 이 책을 사기 직전에 검색할 것 같은 검색어 3개
5. "이 책이 OO만 해결해 줘도 산다"의 OO

마지막으로, 세 페르소나가 공통으로 가장 궁금해할 질문 20개를
'실제 독자가 말하는 문장 그대로' 뽑아 주세요.
(예: "이거 시작하려면 돈이 얼마나 들어요?")
```

### A-3. 경쟁 도서 분석
> 2장 · 퍼플렉시티·딥 리서치로 경쟁 도서 5권을 분석해 시장의 빈틈을 찾을 때 (인용된 리뷰는 원출처 직접 확인)

```
[책 제목 5권 목록]은 제가 쓰려는 전자책과 주제가 겹치는 경쟁 도서입니다.
각 책에 대해 아래 항목을 조사해 표로 정리해 주세요. 출처 링크를 함께 표시하세요.

1. 핵심 타깃 독자와 책이 약속하는 결과
2. 목차 구성의 특징 (어떤 순서로 전개되는가)
3. 독자 리뷰에서 반복되는 칭찬 2가지
4. 독자 리뷰에서 반복되는 불만 2가지
5. 다루지 않는 내용 (이 책을 읽고도 남는 질문)

표 아래에, 다섯 권을 종합해 "이 시장에서 아직 채워지지 않은 빈틈" 3가지를
근거와 함께 제안해 주세요.
```

### A-4. AI 편집자 페르소나 목차 검토 (목차 v2)
> 2장 · 까다로운 편집자에게 비판 권한을 주고, '아는 순서' 목차를 '읽히는 순서'로 리빌딩할 때

```
당신은 20년 경력의 실용서 전문 편집자입니다. 칭찬보다 문제 지적을 우선하는
까다로운 검토자 역할을 맡아 주세요.

[책 정보]
- 주제와 포지셔닝: [포지셔닝 선언문 붙여넣기]
- 핵심 독자: [페르소나 요약 붙여넣기]
- 독자 질문 20개: [목록 붙여넣기]
- 목차 초안: [목차 v1 붙여넣기]

[검토 요청]
1. 이 목차에서 '저자가 아는 순서'로 쓰여 독자가 이탈할 지점을 모두 지적하세요.
2. 독자 질문 20개 중 목차가 답하지 못하는 질문을 찾아 주세요.
3. 분량 대비 가치가 낮아 삭제하거나 합칠 챕터를 지적하세요.
4. 지적을 반영해 '독자가 읽고 싶은 순서'로 목차 v2를 다시 짜 주세요.
5. v2의 각 장 제목 아래에 "이 장을 읽으면 독자는 [ ]를 할 수 있다" 형식의
   한 줄 약속을 붙여 주세요.
```

### A-5. 아침 집필 브리핑 예약 (챗GPT Tasks·클로드 Routines)
> 3장 · 매일 아침 시작 신호와 오늘의 재료를 자동으로 배달받는 루틴을 등록할 때

```
매일 아침 [7시]에 다음 작업을 실행해 줘.

나는 "[책 가제]"라는 전자책을 30일 안에 쓰고 있어. 목차는 다음과 같아: [목차 v2 붙여넣기]
오늘의 집필 스케줄에 따라 아래를 보내 줘.
1. 오늘 쓸 챕터: [스케줄대로 지정 또는 "내가 어제 알려 준 진도의 다음 장"]
2. 그 챕터의 핵심 독자 질문 3개 (내 목차의 한 줄 약속 기준)
3. 글이 풀리게 하는 워밍업 질문 1개 (예: "이 주제에서 독자가 가장 오해하는 것은?")
4. 마지막 줄에 "오늘의 30분, 지금 시작하세요"라고 적어 줘.
```

```
아래 재료로 전자책 출판 기획서를 A4 한 장 분량으로 작성해 주세요.

[재료]
- 경험 자산 목록: [붙여넣기]
- 독자 페르소나 요약: [붙여넣기]
- 포지셔닝 선언문: [붙여넣기]
- 최종 목차 v2: [붙여넣기]
- 30일 스케줄 요약: [초고 시작일, 탈고일, 출간 목표일]

[기획서 구성]
1. 가제 3개 (부제 포함) 2. 한 줄 콘셉트 3. 핵심 독자와 그들의 문제
4. 이 책의 차별점 3가지 5. 목차 요약 6. 예상 분량과 가격대 7. 출간 일정

과장된 수식어 없이, 근거가 있는 내용만 담백하게 써 주세요.
```

## 2부. 집필 (4~6장)

### A-7. 챕터별 글감 인터뷰
> 4장 · 챗봇을 전담 인터뷰어로 세워, 특정 장의 글감을 질문 10개로 캐낼 때

```
당신은 실용서 전문 편집자이자 인터뷰어입니다. 저는 「[책 제목/주제]」라는
전자책을 쓰고 있고, 지금은 [장 번호]장 "[장 제목]"의 글감을 모으는 중입니다.

이 장의 절 구성은 다음과 같습니다:
[목차의 해당 장 절 목록 붙여넣기]

지금부터 저를 인터뷰해 주세요. 규칙:
1. 한 번에 질문 1개만 합니다.
2. 제 답변에서 구체적 사례·숫자·실패담이 나올 만한 지점을 파고듭니다.
3. 답이 추상적이면 "예를 들면요?"라고 되묻습니다.
4. 질문 10개가 끝나면, 제 답변을 절 구성에 맞춰 글감 목록으로 정리해 줍니다.
첫 질문부터 시작하세요.
```

### A-10. 프로젝트 지침 (챗GPT/클로드 프로젝트 세팅)
> 5장 · 책 전용 작업실의 지침 칸에 넣는 상시 규칙 — 문체·작업 규칙을 한 번만 계약해 두는 용도

```
[프로젝트 지침]

당신은 저의 전자책 집필 파트너입니다.

## 책 정보
- 제목(가제): [책 제목]
- 주제 한 줄: [한 줄 콘셉트]
- 독자: [핵심 독자 정의 — 예: AI를 잘 모르는 30~40대 직장인]
- 독자가 이 책에서 얻어야 할 것: [핵심 약속]

## 문체 규칙
- 경어체([예: ~합니다/~하세요]), 한 문단 3~5문장, 짧은 문장 위주
- 독자를 "[호칭]"이라고 부름
- 번역투·과장·근거 없는 수익 보장 표현 금지
- 전문용어는 첫 등장 시 쉬운 말로 풀어 설명

## 작업 규칙
1. 초안 작성 시 반드시 지식 파일의 글감 노트를 우선 사용하고,
   글감에 없는 내용을 지어내지 않습니다.
2. 사실·통계·도구 정보가 필요한데 자료에 없으면, 지어내지 말고
   [확인 필요: 무엇을] 표시를 남깁니다.
3. 저자 개인 경험이 들어갈 자리는 [저자 사례: 설명] 플레이스홀더로 남깁니다.
4. 결과물은 마크다운으로 출력합니다.
```

  질문 3개를 덧붙일 것

### A-14. 내 문체를 지키는 윤문
