# 부록 D. Claude Code 작가용 치트시트

4부(10~12장)의 핵심을 한 장으로 압축했습니다. 명령어는 없습니다. 전부 평범한 한국어 문장입니다. 컴퓨터 옆에 두고, 상황에 맞는 문장을 그대로 말해 보세요.

## 0. 기본 원리 다섯 줄

1. 클로드 코드는 **여러분이 지정한 폴더 안에서** 파일을 직접 읽고 쓰는 AI 조수입니다. 폴더 바깥은 건드리지 않습니다.
2. 파일을 고치기 전에 **허락을 구합니다.** 처음에는 승인 내용을 하나하나 읽고 승인하세요.
3. 큰 작업의 리듬은 **저장 → 조사 → 검토 → 실행**입니다. "아직 바꾸지 말고 먼저 보여줘"가 안전벨트입니다.
4. **CLAUDE.md**는 늘 적용되는 기본 규칙, **스킬(Skills)**은 부를 때만 실행되는 작업 절차, **루틴(Routines)**은 예약 실행입니다. (사훈 / 업무 매뉴얼 / 정기 일정)
5. 자동 실행된 결과물도 **반드시 사람이 검수**합니다. 루틴에게는 원고를 고치게 하지 말고 보고서를 만들게 하세요.

## 1. 시작하기 (10장)

준비: Claude 데스크톱 앱 설치 → Pro 계정 로그인 → 원고 폴더를 작업 폴더로 지정. 클로드 코드는 별도 구독이 아니라 Claude Pro에 포함되어 있습니다.

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 첫 인사 | "이 폴더에 어떤 파일이 있는지 알려주고, 각 파일이 무슨 내용인지 한 줄씩 요약해줘." |
| 원고 피드백 | "[파일명].md 파일을 읽고, 이 글의 장점 2가지와 아쉬운 점 2가지를 알려줘. 아직 파일은 고치지 말고 의견만 줘." |
| 첫 수정 | "[파일명].md에서 맞춤법이 틀린 곳을 찾아서 고쳐줘. 고치기 전에 어디를 어떻게 바꿀 건지 먼저 보여줘." |
| 변경 확인 | "방금 네가 바꾼 내용을 표로 정리해줘. 왼쪽에는 원래 문장, 오른쪽에는 바뀐 문장." |
| 폴더 구축 | "기획/목차.md의 목차에 맞춰 원고 폴더에 챕터별 빈 마크다운 파일을 만들어줘. 파일명은 '번호-장제목' 형식, 각 파일 첫 줄은 '# n장. 제목'으로." |
| 원고 이사 | "이 파일을 목차 기준으로 챕터별 파일로 나눠서 원고 폴더에 저장해줘." |

권장 폴더 구조(11장): `CLAUDE.md` + `기획/`(기획서·목차·페르소나) + `원고/`(01-, 02- 번호 붙인 챕터별 .md) + `자료/` + `산출물/`

## 2. 저장·되돌리기 — 버전 관리 (11장)

원리는 세 동사뿐입니다. **저장한다, 비교한다, 되돌린다.** git 명령어는 클로드 코드가 통역합니다. 습관은 하나: **하루의 집필을 끝낼 때 = 저장을 요청할 때.**

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 최초 1회 | "이 폴더에 버전 관리를 시작해줘." |
| 하루 마감 저장 | "오늘 작업을 버전으로 저장해줘. 바뀐 파일과 내용을 요약해 저장 메모에 남겨줘." |
| 비교 | "[파일명]이 어제 저장본과 비교해서 뭐가 달라졌는지 보여줘. 바뀐 문장을 전후 비교로 정리해줘." |
| 되돌리기 | "[파일명]을 [어제/특정 시점] 버전으로 되돌려줘. 되돌리기 전에 지금 상태도 따로 저장해 두고 진행해줘." |
| 집필 일지 | "지난 2주 동안의 저장 기록을 날짜별로 정리해줘." |

> 되돌리기 전에 "지금 상태도 따로 저장"을 붙이면, 되돌린 것을 다시 되돌릴 수도 있습니다. 어느 쪽으로도 잃는 것이 없습니다.

## 3. 전권 일괄 작업 (11장)

**2단계 원칙**: 먼저 조사만 시키고("아직 바꾸지 말고 목록만"), 확인한 뒤 실행합니다. 큰 일괄 작업 전에는 반드시 저장부터.

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 용어 통일(2단계) | "원고 전체에서 '[바꿀 말]'을 '[통일할 말]'로 통일하려고 해. 아직 바꾸지 말고, 바뀔 위치 목록을 파일별로 먼저 보여줘." → (검토 후) "좋아, 인용문 안은 제외하고 실행해줘. 결과를 표로 보고해줘." |
| 표기 교정 | "원고 전체에서 AI 도구 이름이 처음 나오는 자리를 찾아서 '한글 이름(영문 이름)' 형식으로 병기해줘. 두 번째 등장부터는 한글 이름만 남겨줘." |
| 호칭 변경 | "원고 전체에서 독자를 부르는 호칭을 '[기존]'에서 '[새 호칭]'으로 바꿔줘. 문장이 어색해지는 곳은 자연스럽게 다듬어줘." |
| 중복 점검 | "3장과 7장의 설명이 겹치는지 봐줘." / "목차 파일과 실제 원고 제목이 어긋난 곳을 찾아줘." |
| 개정판 준비 | "전체 원고에서 [도구 이름] 언급 부분을 찾아 목록으로 정리해줘." (14장) |

## 4. 교정·윤문 (6장 + 12장)

6장에서 만든 "나의 교정 체크리스트"가 그대로 스킬의 재료가 됩니다. 원칙은 같습니다. **고치게 하지 말고, 먼저 찾게 하라.**

기본 교정 체크리스트 5종 (여러분의 글버릇으로 계속 추가하세요):

1. 경어체("~합니다/~해 보세요")가 아닌 문장 찾기
2. 번역투 표현 찾기 ("~에 대하여", "~적인", "그것은" 남용)
3. 한 문단이 6문장을 넘는 곳 찾기
4. 도구 이름 첫 등장 시 한글(영문) 병기 확인
5. 금지 표현("무조건", "100% 보장") 찾기

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 교정 보고서 | "원고를 검토해서 보고서만 만들어줘. 원문은 직접 고치지 말고, 표(위치/문제 유형/수정 제안/이유)로만 보고해줘." |
| 선택 반영 | "보고서의 [번호] 제안만 원고에 반영해줘." |
| 체크리스트 갱신 | "교정 스킬에 '[새 항목]' 항목을 추가해줘." |
| 규칙 학습 | "방금 정한 규칙을 CLAUDE.md의 [문체/표기 규칙] 항목에 추가해줘." |

## 5. 자동화 — Skills·Routines (12장)

스킬 후보를 고르는 기준: **같은 지시를 세 번째 입력하고 있다면, 그것이 스킬 후보입니다.**

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 스킬 만들기 | "내가 알려주는 체크리스트를 '[스킬 이름]' 스킬로 만들어줘. 체크리스트: [항목들]. 원고는 고치지 말고 보고서만 산출물 폴더에 저장하도록." |
| 스킬 실행 | "'[스킬 이름]' 스킬을 원고 전체에 실행해줘." |
| 주간 루틴 예약 | "매주 [요일] [시간]에 '[스킬 이름]' 스킬을 실행하고 결과를 산출물 폴더에 날짜별로 저장하는 루틴을 만들어줘. 지난 보고서와의 변화도 요약해줘." |
| 야간 자동 저장 | "매일 밤 원고 폴더의 변경 사항을 버전으로 저장하는 루틴을 만들어줘." |

추천 기본 스킬 3종: **원고 교정** · **팩트체크 표시**(출처 없는 수치에 확인 표시) · **분량 점검**. 응용 스킬 예: 도입-본문 일치 점검, 출처 점검, 실습 난이도 점검.

매주 쓰는 실전 레시피 3종 (스킬로 저장해 한마디로 실행):

| 레시피 | 핵심 요청 |
|---|---|
| 목차 대조 검사 | "기획/목차.md와 원고 폴더의 실제 파일들을 대조해줘. ① 목차에는 있는데 원고 파일이 없는 장 ② 원고 제목과 목차 제목이 다른 장 ③ 목차의 절 중 본문에 없는 것. 표로 정리하고 파일은 고치지 마." |
| 분량 리포트 | "원고 폴더의 챕터별 글자 수(공백 포함)를 세서 표로 만들어줘. 목표는 장당 6,000~9,000자야. 미달/초과 장을 표시하고 전체 진척률(%)도 계산해줘." |
| 마감 대시보드 | "산출물/대시보드.md 파일을 만들어(있으면 갱신해) 줘. ① 챕터별 상태 표 ② 목차 대조 결과 요약 ③ 최근 일주일 작업 기록 ④ 남은 마감일 기준 이번 주 분량 제안." → 매주 월요일 아침 루틴으로 예약 |

## 6. OSMU — 원고에서 홍보 콘텐츠 뽑기 (12장)

공식: **원고 1챕터 → 카드뉴스 1세트 + 쓰레드 글 5~7개 + 릴스 대본 1편 + 뉴스레터 요약 1편.** 원칙: **AI 초안 + 사람 검수 + 도구 발행.**

| 상황 | 이렇게 말해 보세요 |
|---|---|
| 챕터 단위 | "[챕터 파일명]을 읽고 산출물 폴더에 만들어줘: 쓰레드용 글 5개, 카드뉴스 문안 1세트(8장), 릴스 대본 1편, 뉴스레터 요약 1편. 문체는 CLAUDE.md 규칙을 따르고, 파일마다 '초안' 표시를 넣어줘." |
| 전권 일괄 | "원고 전체를 읽고 산출물 폴더에 홍보 콘텐츠 초안을 만들어줘: 보도자료.md, 상세페이지.md, SNS/ 폴더(장별 쓰레드 글 5개씩), 뉴스레터-창간호.md. 전부 초안 표시하고 CLAUDE.md 문체 규칙을 따라줘." |
| 톤 관리 | 매체별 톤 가이드(보도자료=격식 문어체, 쓰레드=짧은 구어체, 상세페이지=고민에 말 거는 톤)를 CLAUDE.md에 한 번 적어 두면 모든 OSMU 작업에 자동 적용 |

## 7. CLAUDE.md 뼈대 (11장)

작업 폴더에 이 이름으로 두면 클로드 코드가 매번 자동으로 읽는 "내 책의 업무 매뉴얼"입니다. 직접 쓸 필요 없이 "지금까지 정한 문체 규칙을 정리해서 CLAUDE.md 파일로 만들어줘"라고 시키고, 새 규칙이 생길 때마다 "방금 정한 규칙, CLAUDE.md에 추가해줘"라고 말하면 됩니다.

```markdown
# 이 책의 집필 규칙

## 책 소개
- 제목(가제) / 독자 / 저자 화자

## 문체
- 경어체("~합니다 / ~해 보세요"), 한 문단 3~5문장, 짧은 문장 위주
- 독자는 "여러분"이라고 부른다. 번역투·과장 표현 금지

## 표기 규칙
- 도구 이름 첫 등장 시 한글(영문) 병기. 용어 통일 목록(O/X)
- 금액 표기 기준

## 금지 사항
- 수익 보장 표현, 근거 모르는 통계 수치

## 폴더 안내
- 원고는 원고/ 폴더의 챕터별 파일, 목차 기준은 기획/목차.md
- 원고를 수정하기 전에는 항상 바뀔 내용을 먼저 보여줄 것
```

마지막 줄이 핵심입니다. "수정 전에 먼저 보여줄 것"을 규칙 파일에 넣어 두면, 검토 후 실행이라는 안전한 작업 리듬이 기본값이 됩니다.
